# 现实前沿簿

这个目录记录一次实验：在「封闭学科」（数学）里，用大模型的跨领域知识加上计算，找人类还没有记录的结果。
所有结果都由一个智能体证明或计算，再由另一个**不复用其代码**的智能体独立复核，并单独检索文献判断是否新颖。
日期：2026-10-01。OEIS 数据为当天快照。

## 两条路线

**路线一：OEIS 跨领域巧合。** 在 OEIS 全部 399,822 条数列里，找数值长期一致、但两边条目互不提及的数列对。

| 步骤 | 数量 |
|---|---|
| 至少 18 项一致的数列对 | 5,339 |
| 至今没有分叉的 | 3,287 |
| 两边条目互不提及的 | 331 |
| 分诊为「非平凡相等」的 | 23 |
| 深挖（证明 + 独立复核 + 查新） | 7 |

**路线二：最新猜想找反例。** 从 2025 到 2026 年的 arXiv 论文里挑出 18 个可以用有限计算证伪的猜想，攻了其中 3 个。

## 目录

- `find_coincidences.py`、`filter_unlinked.py`：路线一的搜索脚本。
- `data/`：候选数列对和分诊判定。
- `theorems/`：路线一 7 个深挖目标的证明、代码和复核记录。
- `conjectures/`：路线二的攻坚与复核代码，以及 `hunt_result.json`。
- `workflows/`：深挖用的多智能体工作流脚本。

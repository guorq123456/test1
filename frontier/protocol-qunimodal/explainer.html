什么时候，一串数会「先升后降」？

这一页讲一个很窄的组合数学问题：一类多项式的系数什么时候是单峰的。我们用几张小图说清楚三件事：问题是什么，发现了什么，以及哪些结论靠得住、哪些还只是猜测。

问题是什么

数一数「有多少种凑法」

先选几个正整数 a₁, …, aₖ，再选一个步长 r 和一个次数 b。我们关心这个多项式：

P_b(q) = [a₁]_q · [a₂]_q ⋯ [aₖ]_q · [b]_{q^r}

其中 [n]_q = 1+q+…+q^(n−1)，[b]_{q^r} = 1+q^r+q^(2r)+…+q^(r(b−1))。

别被符号吓到。它的系数有个很直白的意思：q 的 n 次方前面的系数，就是把 n 写成

n = x₁ + x₂ + … + xₖ + r·y　　（0 ≤ xᵢ < aᵢ，0 ≤ y < b）

的方法有几种。比如 a = (2, 3)、r = 4、b = 2 时，n = 5 只能取 y = 1，剩下 x₁+x₂ = 1，有 (1,0) 和 (0,1) 两种，所以 q⁵ 的系数是 2。

把所有系数排成一排画成柱子，如果柱子先不降、再不升（中间可以有平台），就叫单峰。下面两张图用的是同一组 a = (2, 3)、b = 2，只是步长不同。蓝色是 y = 0 的凑法，橙色是 y = 1 的凑法，它们其实是同一座小山，只是往右平移了 r 格。

r = 2 单峰
两座小山挨得近，叠成一座大山：1, 2, 3, 3, 2, 1
r = 4 不单峰
两座小山离得远，中间凹下去：1, 2, 2, 1, 1, 2, 2, 1
y = 0 的凑法y = 1 的凑法

所以研究的问题是：给定 a 和 r，哪些 b 能让 P_b 单峰？把这些 b 收集起来，记作集合 U。另外记 F = Σ⌊aᵢ / r⌋（每个 aᵢ 里能装下几个完整的 r，加起来）。

起点是 2026 年 5 月的论文 arXiv:2605.12822 的猜想 5.4：如果 r 整除某个 aᵢ，或者 b ≤ 1+F，就一定单峰；当 k ≤ 3 或 r ≤ 3 时，这个条件也是必须的。后半句「必须」在文献里已经被别人推翻了（不是我们）：(1+q)⁶(1+q³) 是单峰的，可这里 b = 2，比 1+F = 1 大。

一个反直觉的现象

b 变大，单峰性可以「丢了又回来」

直觉会说：b 越大，往右平移的拷贝越多，越难单峰，所以 U 应该是一段从 1 开始的连续整数。可下面这个例子不是这样。取 r = 6，a = (2, 3, 3, 4, 4, 4, 5)：

放大看山顶 （纵轴不从 0 开始，只为看清小起伏）
正常的系数凹下去的地方（破坏单峰）

b = 1 单峰，b = 2 不单峰（山顶 947, 946, 947 凹了 1），b = 3 又单峰了，b = 4 再次不单峰。所以这里 U = {1, 3}：U 不一定是一段区间。

「缺一个点」

U 最多只缺一个点

那 U 能乱到什么程度？我们的主要结论（代号 S2）说：不会太乱。设 B* 是 U 里最大的数，那么 U 只有两种样子：

  • 完整的一段 [1, B*]；或者
  • [1, B*] 挖掉倒数第二个点 B*−1。
b = 1 到 B*+2，哪些在 U 里
在 U 里（单峰）被挖掉的 B*−1不在 U 里

上一节的 U = {1, 3} 也是这个样子：B* = 3，挖掉了 2。

可信度要说清楚：S2 在 r = 4、5、6 时已经证明（计算机辅助证明）；r ≥ 7 还是猜想。它的证据很多（见下一节和「现在的地图」），但证据不等于证明。

看起来对、其实不对

小范围全对，不代表永远对

这次研究里有两条说法，在大量数据上都成立，后来还是被推翻了。第一个反例由两名复核者各自独立重算确认；第二个由综合者用两套程序算出、再由审稿人独立重算，还没走「两名复核者重写代码」那一步。

一、「逐个类对」的局部论证

一种只看局部、两两比较的证明思路。在 r ≤ 400 的所有数据上都成立。

在 r = 8595（k = 127，aᵢ 都在 1687 到 1693 之间）失败；另一位独立复核者又在 r = 10331 找到一个同类型的反例。不过这个例子的整体答案 U = {1, 2, 3, 5} 仍然符合 S2，坏掉的是这条证明路线，不是 S2 本身。

二、「U 的最大值就等于 Bd」

Bd 是一个能直接算出来的上界（已证明 max U ≤ Bd）。曾经看上去它总是恰好取到：

穷举实例 100,488 个：全成立随机实例 约 16,000 个：全成立

在 r = 500、k = 39 失败：Bd = 72，但 U = [1, 70]，差了 2。

另外，第 2 轮提出的一个「余数证书」条件也在 r = 57 被推翻。教训：小范围的大量证据，也可能误导人。

现在的地图

按可信程度分一分

「已证明」的每一条，都由另一个模型扮演的复核者逐步核对并通过。

复现的文献里已有
  • 充分性：b ≤ 1+F 就一定单峰（对所有 r、k）。
  • r = 2、r = 3、k ≤ 2 这几种情况的完整答案。
已证明
  • 精确判定算法：给定任何参数都能算出 U（是算法，不是公式）。
  • 上界：max U ≤ Bd ≤ T6。
  • 结构：U = [1, N*] ∪ {N*+2, N*+4, …, β}，N* 和 β 的奇偶都与 1+F 相同。
  • 「缺一个点」S2：r = 4、5、6 成立（计算机辅助）。
  • 闭式：「中间余数」（落在 [2, r−2] 的余数）最多两个时，U = [1, T6]；恰好三个、其余余数为 ±1 时，U = [1, T6 − 2·FIRE]。对所有 r 成立。
  • 超出量 B*−1−F 随 k 线性增长，带一个 −ln k 修正；更细的部分不是最终周期的。
猜想未证明
  • S2 对所有 r 成立；以及更强的 (O)：[1, Bd−2] ⊆ U。目前 0 反例：100,488 个穷举、约 16,000 个分层随机、r 到 50,000 的实例、299 次对抗优化。
  • 四个中间余数时的修正规则；稳定化猜想 Q。
被推翻
  • 逐个类对的局部论证（r = 8595、r = 10331）。
  • 「max U = Bd」（r = 500，k = 39）。
  • 第 2 轮的余数证书条件（r = 57）。
  • 猜想 5.4 的必要性部分（文献里别人推翻的）。
不存在证明了「没有」
  • 只看余数统计量的公式不存在（r = 6 有一对反例；四个中间余数时 r = 20 有一对）。
  • 最优稳定阈值 L0 不是 (r, k, S, τ) 的函数。
怎么做出来的

一套事先定好的流程，跑了 3 轮

用户事先定了一个 7 步协议（从第 0 步「文献先行」算起）。每轮按顺序走一遍，最后看停止规则决定要不要再来一轮。

3 × 83 轮，每轮 8 个独立探索者
H1–H5隐藏留出集，每轮换新；最后一套 r 到 900、k 到 200
11 / 11第 3 轮复核的结论全部通过

第 3 轮的 11 项结论里，有两项是补全了定义、重新复核后才通过的。原因是协调者交接材料里漏写了定义，不是数字算错。

限制

这些地方要打个折扣

  • 所有复核都是 AI 复核。没有人类数学家检查过。
  • 「文献里没找到」不等于「是新的」。第 1 轮就曾把一个已有结果误标为新结果，后来纠正了。
  • 问题本身很窄。即使全对，影响面也有限。
  • 停下来是因为用户要求收尾。协议自己的停止规则并没有满足，第 3 轮仍在产生新的约束。

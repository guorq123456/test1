PROOF FILE (E7): where unimodality of P(q) = prod_i [a_i]_q * [b]_{q^r} fails, and why it is (almost) monotone in b.

Notation.
  r>=2, k>=1, a_1..a_k>=1, b>=1.  p(q) = prod_i [a_i]_q = sum_{j=0}^{D} p_j q^j,  D = sum_i (a_i - 1).
  P(q) = p(q) [b]_{q^r} = sum_{n=0}^{N} c_n q^n,  N = D + r(b-1),  h = floor(N/2).
  G(q) = p(q)(1-q)/(1-q^r) = p(q)/[r]_q  in Z[[q]],  G = sum_{i>=0} g_i q^i.  Convention: p_j = 0 for j outside
  [0,D]; g_i = 0 and c_i = 0 for i < 0.
  X := min{ i : g_i < 0 } - 1   (X = +infinity if G has no negative coefficient).
  For t in Z/rZ: S_t := sum_{j = t mod r} p_j (residue-class sums of p).
  F := sum_i floor(a_i/r);  e_i := a_i mod r;  S := sum_i (e_i - 1) (when no e_i = 0).  Then D = rF + S.

Lemma 1. p and P are palindromic: p_j = p_{D-j}, c_n = c_{N-n}; p has positive coefficients and is unimodal.
  Proof. Each [a]_q is palindromic with nonnegative coefficients and unimodal, [b]_{q^r} is palindromic; a product of
  palindromic polynomials is palindromic (degrees add).  A product of symmetric unimodal polynomials with nonnegative
  coefficients is symmetric unimodal (Stanley 1989, Prop. 1); apply to p.  Positivity: every 0<=j<=D is a sum of
  admissible exponents.  QED

Lemma 2. A palindromic sequence c_0..c_N is (weakly) unimodal iff c_0 <= c_1 <= ... <= c_h, h = floor(N/2).
  Proof. (<=) For n >= ceil(N/2): c_{n+1} = c_{N-n-1} <= c_{N-n} = c_n since N-n <= floor(N/2) = h (and both
  indices N-n-1 < N-n lie in [0,h]).  If N is odd, c_h = c_{h+1} by palindromy.  So c rises weakly to h, is flat
  between h and ceil(N/2), and falls weakly afterwards: unimodal.
  (=>) Let c be nondecreasing on [0,m] and nonincreasing on [m,N].  If m >= h we are done.  If m < h, put
  m' = N-m > h.  Then c_m = c_{m'} and, c being nonincreasing on [m,N], c_m >= c_j >= c_{m'} = c_m for all
  j in [m,m'], so c is constant on [m,m'] which contains [m,h]; hence nondecreasing on [0,h].  QED

Lemma 3 (generating identity). (1-q) P(q) = G(q) (1 - q^{rb}).  Hence for every i >= 0:
      c_i - c_{i-1} = g_i - g_{i-rb}.
  Proof. [b]_{q^r} = (1-q^{rb})/(1-q^r), so (1-q)P = p(1-q)(1-q^{rb})/(1-q^r) = G(1-q^{rb}).  Compare
  coefficients of q^i.  QED

Lemma 4 (recurrence / partial residue sums). g_i = (p_i - p_{i-1}) + g_{i-r}; equivalently
      g_i = sum_{0<=j<=i, j = i mod r} (p_j - p_{j-1}) = L_i - L_{i-1},  where L_n := sum_{0<=j<=n, j = n mod r} p_j.
  Proof. G(1-q^r) = p(1-q) gives the recurrence; unrolling it gives the sum; p/(1-q^r) = sum_n L_n q^n and
  G = (1-q) * p/(1-q^r).  QED

THEOREM 5 (exact criterion).  P is unimodal  <=>  g_i >= g_{i-rb} for all 0 <= i <= h.
  Proof. By Lemma 1 and Lemma 2, P unimodal <=> c_{i} - c_{i-1} >= 0 for 1 <= i <= h (the case i = 0 reads
  c_0 = 1 >= 0 and g_0 = p_0 = 1 >= 0, always true).  By Lemma 3 this is g_i - g_{i-rb} >= 0.  QED

COROLLARY 6 (decomposition into a monotone part and an overlap part).
  P unimodal  <=>  (I)  h <= X      and     (II)  g_i >= g_{i-rb} for all rb <= i <= h.
  Proof. (=>) (II) is part of Theorem 5.  Suppose (I) fails: i0 := X+1 <= h, g_{i0} < 0, and g_j >= 0 for
  0 <= j < i0.  If i0 < rb then g_{i0-rb} = 0; otherwise 0 <= i0-rb < i0 so g_{i0-rb} >= 0.  Either way
  g_{i0} - g_{i0-rb} < 0, contradicting Theorem 5.
  (<=) For i < rb: g_i - g_{i-rb} = g_i >= 0 because i <= h <= X.  For rb <= i <= h use (II).  QED

COROLLARY 7 (monotonicity).
  (a) Condition (I) is monotone in b: h = floor((D + r(b-1))/2) is nondecreasing in b.  Explicitly (I) holds
      iff  r(b-1) <= 2X + 1 - D  iff  b <= B_A := 1 + floor((2X+1-D)/r)   (all b if X = infinity).
      [h <= X <=> (D+r(b-1))/2 < X+1 <=> D + r(b-1) <= 2X+1.]
  (b) (II) is vacuous when h < rb, i.e. when D <= r(b+1) - 1.  So for b >= D/r, P unimodal <=> (I).
  (c) Hence if P is unimodal at b and b' < b, then P is unimodal at b' unless (II) fails at b', which requires
      D >= r(b'+1).  In particular every failure of monotonicity in b is caused by an overlap failure (II),
      never by (I).
  Proof. Immediate from Corollary 6.  QED

COROLLARY 8 (location of the first violation).  If P is not unimodal, let t be the first index with
  c_t > c_{t+1}.  Then t+1 = min{ i <= h : g_i < g_{i-rb} } and exactly one of the following holds:
    Type I : g_{t+1} < 0; then t = X (a position that does not depend on b);
    Type II: g_{t+1} >= 0 > g_{t+1} - g_{t+1-rb}; then t+1 >= rb (overlap of G with its shift by rb).
  Proof. By Lemma 2 a non-unimodal palindromic sequence has a strict descent at some index < h, so the first
  strict descent t satisfies t+1 <= h, and by Lemma 3 t+1 is the first i with g_i < g_{i-rb}.
  Claim: g_i >= 0 for all 0 <= i <= t.  Induction on i: g_i >= g_{i-rb} (as i < t+1), and g_{i-rb} is 0 (negative
  index) or >= 0 by the induction hypothesis (index < i).  Hence if g_{t+1} < 0, t+1 is the first negative
  coefficient of G, i.e. t = X.  If g_{t+1} >= 0 then g_{t+1-rb} > g_{t+1} >= 0, which forces t+1-rb >= 0.  QED

LEMMA 9 (window for X).
  (a) If r | a_i for some i then X = infinity.
  (b) Always X >= floor(D/2).
  (c) If r divides no a_i, the residue sums S_t are not all equal, j* := max{ j in {0,...,r-1} : S_j > S_{j-1 mod r} }
      exists, and X <= D - j* <= D.
  Proof. (a) (1-q)[a_i]_q/(1-q^r) = (1-q^{a_i})/(1-q^r) = [a_i/r]_{q^r}, so G = prod_{l != i}[a_l]_q * [a_i/r]_{q^r}
      is a polynomial with nonnegative coefficients.
  (b) By Lemma 1 and Lemma 2 (applied to p), p_j - p_{j-1} >= 0 for 1 <= j <= floor(D/2), and p_0 - p_{-1} = 1.
      By Lemma 4, for i <= floor(D/2) every summand of g_i is >= 0, so g_i >= 0.  Hence X+1 > floor(D/2).
  (c) Non-constancy: if all S_t equal S_0 then for a primitive r-th root of unity z, p(z) = sum_t S_t z^t
      = S_0 sum_t z^t = 0; but p(z) = prod_i (1 - z^{a_i})/(1 - z) and 1 - z^{a_i} != 0 when r does not divide a_i.
      So S is non-constant, and a non-constant sequence on the cycle Z/rZ has a strict increase somewhere: j* exists.
      For n >= D - r + 1, every j = n (mod r) with j <= D satisfies j <= n (the next one, n + r, exceeds D), so
      L_n = S_{n mod r}.  Hence by Lemma 4, for i >= D - r + 2:  g_i = S_{i mod r} - S_{(i-1) mod r}.
      Palindromy p_j = p_{D-j} maps residue class t onto class D - t, so S_t = S_{(D-t) mod r}.  For 0 <= j <= r-1
      the index i = D+1-j is >= D-r+2, so  g_{D+1-j} = S_{D+1-j} - S_{D-j} = S_{(j-1) mod r} - S_{j mod r}.
      With j = j*: g_{D+1-j*} < 0, hence X + 1 <= D + 1 - j*.  QED

COROLLARY 10 (proven necessary condition: where failure is forced).
  If r divides no a_i and P is unimodal, then  r(b-1) <= 2X + 1 - D <= D + 1 - 2 j*, i.e.
        b <= 1 + F + kappa,   kappa := floor((S + 1 - 2 j*)/r)        (S = sum (e_i - 1), e_i = a_i mod r).
  In particular r(b-1) <= D+1 always, and if S <= r-2 (e.g. k = 1) then unimodal => b <= 1 + F.
  Proof. Corollary 6 (I): h <= X; Lemma 9(c): X <= D - j*.  floor((D + r(b-1))/2) <= D - j* gives
  D + r(b-1) <= 2D - 2j* + 1.  Divide by r using D = rF + S.  If S <= r-2 then S + 1 - 2j* <= r - 1, kappa <= 0.  QED

LEMMA 11 (j* and kappa depend only on the residues e_i that are >= 2).
  Proof. Let z be a primitive r-th root of unity.  S_t = (1/r) sum_{s=0}^{r-1} z^{-st} p(z^s), so
  S_j - S_{j-1} = (1/r) sum_{s=1}^{r-1} (z^{-sj} - z^{-s(j-1)}) p(z^s).  For w = z^s != 1, w^r = 1:
  [a + r]_w = [a]_w + w^a [r]_w = [a]_w since [r]_w = (1-w^r)/(1-w) = 0; so [a]_w depends only on a mod r, and
  [a]_w = 1 when a = 1 mod r.  Hence every difference S_j - S_{j-1}, so j*, depends only on the multiset
  E = { e_i : e_i >= 2 }.  S = sum (e_i - 1) likewise.  So kappa = kappa(r, E).  QED

LEMMA 12 (r = 3 closed form).  For r = 3 and no 3 | a_i, let n2 = #{ i : a_i = 2 mod 3 }.  Then kappa = 2 floor(n2/6),
  so: P unimodal  =>  b <= 1 + sum floor(a_i/3) + 2 floor(n2/6).
  Proof. w = e^{2 pi i/3}.  [a]_w = 1 if a = 1 (mod 3) and [a]_w = 1 + w = -w^2 if a = 2 (mod 3).
  p(w) = (-1)^{n2} w^{2 n2}, p(w^2) = conjugate.  S_t = (1/3)(p(1) + 2 Re(w^{-t} p(w)))
  = (1/3)(p(1) + 2 eps Re(w^{2n2 - t})), eps = (-1)^{n2}; Re(w^m) = 1 if 3 | m, else -1/2.
  So with t0 = 2 n2 mod 3:  S_{t0} = (p(1) + 2eps)/3 and the other two equal (p(1) - eps)/3.
  n2 even: S_{t0} is the unique larger value, the only strict increase S_{j-1} < S_j is at j = t0, j* = t0.
  n2 odd : S_{t0} is the unique smaller value, the only strict increase is at j = t0 + 1 (mod 3), j* = (t0+1) mod 3.
  S = n2 (each residue-2 entry contributes 1).  Table (n2 = 6s + u):
     u=0: t0=0, j*=0, floor((n2+1)/3)=2s;   u=1: t0=2, j*=0, floor((n2+1)/3)=2s;
     u=2: t0=1, j*=1, floor((n2-1)/3)=2s;   u=3: t0=0, j*=1, floor((n2-1)/3)=2s;
     u=4: t0=2, j*=2, floor((n2-3)/3)=2s;   u=5: t0=1, j*=2, floor((n2-3)/3)=2s.
  So kappa = 2s = 2 floor(n2/6).  Apply Corollary 10.  QED
  Consequence: for r = 3 the necessity clause of Conjecture 5.4 holds whenever n2 <= 5 (in particular k <= 5);
  the known counterexample (1+q)^6 (1+q^3) has n2 = 6, the first value where kappa > 0.

COROLLARY 13 (computer-assisted, uses only fit-box computations).  For r <= 6, if at most three of the a_i have
  a_i mod r not in {0,1} (in particular if k <= 3), then P unimodal => r | a_i for some i or b <= 1 + sum floor(a_i/r).
  Proof. By Lemma 11 kappa depends only on (r, E) with |E| <= 3, entries in {2..r-1}.  Every such pattern occurs as
  a base tuple a = E inside the fit box, and kappa(r,E) = 0 for all of them (script kappa.py: 1+4+10+20+35 = 70
  patterns, all kappa = 0).  Apply Corollary 10.  QED
  (Same argument: for r <= 6 and any E with |E| <= 8, unimodal => b <= 1 + F + kappa(r,E), with kappa(r,E) in {0,2,4}
  tabulated by kappa.py.)

What is NOT proven here: sufficiency (that b <= 1 + F, or b <= B_A, implies unimodality) and the empirical facts
that (II) almost never bites, that X >= D - 2(r-2), and that kappa and B_A - 1 - F are always even.

# 第 1 步：动手前写下的「概率 1」

问题：对 r≥2、k≥1、aᵢ≥1、b≥1，P(q) = [a₁]_q⋯[a_k]_q·[b]_{q^r} 的系数何时（弱）单峰。
写于派发探索者之前（2026-10-01）。上一轮留下的未证规则：r=3 且没有 aᵢ 被 3 整除时，单峰 ⇔ b ≤ F+1+2⌊S/6⌋，其中 S=#{aᵢ≡2 mod 3}，F=Σ⌊aᵢ/3⌋。

## 默认的前 5 个动作，各配一个替代项

| # | 默认动作 | 替代项 |
|---|---|---|
| A1 | 把问题形式化为系数序列 c_t，直接算 c_t 判单峰 | 概率形式化：P 归一化后是 X=U₁+…+U_k+rV 的分布列，用单位根滤波 / 特征函数研究 |
| A2 | 用论文用过的统计量（r、F、余数计数、b）去拟合规则 | 不预设特征：让数据挑特征，系统地找「统计量相同但单峰性不同」的对 |
| A3 | 用「周期窗口」论证：在 [D, r(b−1)] 上 c_t 以 r 为周期，归结为余数和的符号 | 用其他证明机制：组合单射 / 对称链，或对数凹性与交错根 |
| A4 | 先做 r=3，再推广 | 直接攻一般 r，从 P 在 r 次本原单位根处的取值出发找统一规则 |
| A5 | 用小参数穷举验证 | 对抗式搜索：爬山 / 结构化族（全相等、两种取值）专门找反例 |

## 默认的前 5 个假设，各配一个替代项

| # | 默认假设 | 替代项 |
|---|---|---|
| H1 | 单峰性只取决于少数汇总统计量（余数计数、F、b） | 取决于更细的结构，汇总统计量规则不存在 |
| H2 | 失去单峰只发生在中间的周期平台附近 | 也可能发生在别处，比如开头的台阶处 |
| H3 | 对 b 单调：b 单峰则更小的 b 也单峰 | 对 b 不单调，存在单峰「窗口」 |
| H4 | 论文的充分性部分成立（r∣某 aᵢ，或 b≤1+F ⇒ 单峰） | 充分性在已测范围外有反例 |
| H5 | r=3 规则对 S 的周期是 6 | 周期还依赖别的量，比如 T=#{aᵢ≡1 mod 3} |

## 答案的形状（至少三种，含「不存在」）

1. **闭式不等式**：用 (r, 余数计数, F, b) 写出的显式条件，比如 b ≤ F+1+2⌊S/6⌋。
2. **有限状态 / 周期表描述**：对每种余数分布（模某个数），临界 b 由一张有限表加线性项给出。
3. **渐近式**：k 足够大时，单峰 ⇔ b ≤ D/r − g(余数分布) + O(1)。
4. **不存在**：不存在只依赖汇总统计量的刻画；以两组统计量相同、单峰性不同的参数作为证据。

## 派发方案

每个替代项交给一个独立探索者，加上一条默认主路，共 8 条路：

| 探索者 | 路线 | 对应 |
|---|---|---|
| E1 | 默认主路：r=3 拟合 (S,F,b) 规则并用周期窗口证明 | A2、A3、A4 的默认 |
| E2 | 单位根滤波 / 特征函数 | A1′ |
| E3 | 不预设特征，找「统计量相同、单峰性不同」的对 | A2′、H1′、形状 4 |
| E4 | 组合单射或对数凹性证明充分性方向 | A3′ |
| E5 | 直接攻一般 r | A4′ |
| E6 | 对抗式搜索论文充分性的反例 | A5′、H4′ |
| E7 | 失败位置与对 b 的单调性 | H2′、H3′ |
| E8 | 统计量 S 之外的变量（T、模 2r 的余数） | H5′ |

拟合范围（探索者可算）：r∈{2,…,6}，k≤8，aᵢ≤12，b≤60。
留出范围（探索者不得计算）：其余一切参数。第 1 轮留出集已在派发前算好，放在探索者不知道的位置。

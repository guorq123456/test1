# 第 1 步对比训练的试拟合：在老师对比对上选定 μ、L2 和起点（只拟合，不开门）

条件：对手卡表已知（牌序、手牌未知）。架构线 2026-10-09 09:39Z 和 10:00Z 布置；分析线第 1 步预注册（8740d0f）要求 μ、L2 和起点在看任何第 1 步留出读数之前定下。这里只用老师对比对，没碰第 1 步的数据。

## 数据

- 分析线 753d531 的 `analysis/card-value/student_read/teacher_ends.jsonl.gz`，sha256 前 16 位 `1340e4f35eba940c`；读法是他们的 teacher_ends.py（fc3c942，和 753d531 相同）。
- 18,161 个（局面 × 种子），250,928 个对比对。去掉两条线动作相同的 470 对，再去掉至少一端在回合中途对局已结束的 7,177 对，剩 243,281 对。
- 回合末是结算过回合末效果、对手回合还没开始的局面（ENDED 模型看到的样子）；特征从行动方视角算，版本 2，不加具名特征集（同现装原版 ramp-ramp）。
- 按确定化逐个配对（mode det），等权。校准项用学生数据的自对弈回合末（selfplay.jsonl，17,694 行）。
- 按局切分：g % 11 == 0 留出（22,491 对）。

## 选参数（`c1_run.py` 第 1 段，`c1_edge.py` 补扫边缘）

- 网格：μ ∈ {0.03, 0.1, 0.3, 1}，L2 ∈ {1e-4, 1e-3, 1e-2}，起点 ∈ {零, 现装模型}。在四分之一的训练局（g % 11 != 0 且 g % 4 == 0）上拟合 2000 轮，读全部留出局。
- 预先定的规则：在留出校准 log loss 不比现装差超过 0.005 的设置里，选留出对比误差（σ(E(a)) − σ(E(b)) − dT 的平方的平均）最小的。
- 读数（run.log 的 grid 行，edge.log 补扫）：
  - 起点不影响结果：零起点和现装起点的对比误差差不到 1e-5，说明收敛。
  - L2：1e-4 优于 1e-3 和 1e-2；补扫 1e-5 和 0 反而略差（0.03420 对 0.03415），所以 1e-4 是内部最优。
  - μ：越小对比误差越低、校准越差。0.03 → 0.034148；补扫 0.01 → 0.034038，只低 0.0001，在噪声量级，而校准变差（0.5948 对 0.5942）。
- **选定：μ = 0.03，L2 = 1e-4，起点 = 零。**
  - μ 不取 0.01：增益在噪声量级，校准锚更弱，纯对比时截距几乎不可识别。
  - 起点取零：和现装起点结果一样，而且不依赖现装模型。
- 收敛：3000 轮和 6000 轮系数最大差 0.0019，留出读数相同到第四位。第 1 步用 3000 轮。

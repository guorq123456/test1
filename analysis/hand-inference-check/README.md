**定义核过，没有问题**：
- 重合比例：从对方「手牌 + 牌库」里抽 n 张（n = 真实手牌张数），同种牌按真实张数封顶，算猜中的比例，再对抽样次数取平均。
- 加权无放回抽样用 u^(1/w) 的键（Efraimidis–Spirakis）。被标记的牌 w = α，其余 w = 1；α = 1 就是现在的均匀抽样。
- 「被标记牌在手比例」按 uid 判断是否在真实手牌里；基础比例 = 手牌张数 ÷（手牌 + 牌库）的逐点平均。

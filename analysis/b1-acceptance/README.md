## 3. evolve_use 不降

总体 85% → 83%（−2.6，−11～+5），不显著。但"A 档在手够不着"和"收益牌在手够不着"两格从 100% 降到 87～88%。

## 结论

前三项里：
- 第 1 项（关键判据）没过：探针上 b1 没往 Salem 的方向动，点估计反而更远；自对弈里最关键的"A 档在手、够不着"一格完全没动。
- 第 2 项有轻微移动，在噪声以内。
- 第 3 项没有显著下降。

按验收顺序，strong 等算力闸门要等架构线程决定。这和 1 号在分叉数据里看到的情况一致："留点"那支的结果比对照差（payoff −10.5% ± 2.7%），说明训练数据里的留法太粗，模型学不到 Salem 那种按目标留点。

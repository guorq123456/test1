## 1. 「最强」能补上多少运营差距

**范围**：6 个大差距开头，就是三道题加上另外三个复测也过了的：k = 320、518、445、313、455、329（`README-puzzles.md`）。

**做法**
1. **两档各打这一回合 8 次**：
   - 从记录里的真实局面出发（同第 0 步、复测），`level-strong` 和 `mcts:1043+plan+learned+phased` 各用 8 个种子打完这一回合。智能体自己确定化对手的手牌。
   - 种子：第 i 个开头（i 是 M4 的号）用 67300000 + 100 i + r，r = 0～7。两档用同一批种子。
2. **各取出现最多的回合末**：按 `search.lethal.state_key` 数，出现最多的那个；并列时取种子最小的那个。
   - 照报：每档 8 次里有几种不同的回合末，取到的那个出现几次，和 Salem 的回合末是否相同。
3. **三条线打到终局**：Salem 的线、`level-strong` 的线、1043 的线，各自从回合末出发。
   - 走 default 方向，K = 48，双方 `mcts:100+plan+learned+phased`，同 M4 和复测。
   - 新种子 `direction_rollout(seed = 67350000 + 500 i)`；三条线用同一批 48 个种子，配对。

**交回**
- 每个开头三条线的胜率，以及三个配对差：Salem − 1043、Salem − level-strong、1043 − level-strong。区间按种子成对重抽 2000 次（随机数种子 0），取百分位。
- **1043 补上的差距**：
  - 每个开头 (W₁₀₄₃ − W_ls) ÷ (W_Salem − W_ls)，分母 ≤ 0 的不算；
  - 6 个合起来 Σ(W₁₀₄₃ − W_ls) ÷ Σ(W_Salem − W_ls)，区间在每个开头内按种子重抽 2000 次。
- **J49**（架构线程，置信 **50%**）：6 个里至少 4 个，1043 追平 Salem，即「Salem − 1043」的配对差区间含 0。
  - 1043 明显比 Salem 好（区间整个在 0 以下）的也算追平，也就是看下沿 ≤ 0。这是分析线对「追平」的读法；照报这种开头有几个。

## 2. 搜索档位的分歧和根节点走法数（给 `+complex` 做底）

**范围**：第 0 步的现装自对弈 `selfplay.jsonl`。150 局 `level-strong` 对 `level-strong`，原版跳费龙镜像，9489 个动作。

**做法**
1. **决策点**：
   - 每个动作之前的局面，只取主阶段、合法走法 ≥ 2 的（换牌和只剩一个走法的不算）。
   - 用 `random.Random(67320000).sample` 不放回抽 **2000 个**。
2. **分档**：按根节点的合法走法数分四档，分界是这 2000 个的 25%、50%、75% 分位数 q₁、q₂、q₃。
   - 第一档 ≤ q₁，第二档 (q₁, q₂]，第三档 (q₂, q₃]，第四档 > q₃。
   - 分界只看走法数，在跑任何搜索之前算出来，写进这里再跑。
3. **两档各搜一次**：
   - `level-strong` 和 `mcts:1043+plan+learned+phased` 在同一个局面上各决定一次，同种子（第 d 个决策点用 67330000 + d）。
   - 比较选的走法是否相同，按动作的字典表示逐项相等。

**交回**
- 每档的决策点数、两者选择不同的个数和比例（Wilson 95% 区间）；总的不同比例。
- 最高档 ÷ 最低档的比值，区间按决策点重抽 2000 次。
- **J50**（架构线程，置信 **70%**）：最高一档的不同比例至少是最低一档的 2 倍。看点估计。

## 种子

- 库 **67300000～67399999**：
  - 第 1 件打回合：67300000 + 100 i + r（i ≤ 84，r ≤ 7）；
  - 第 2 件抽样：67320000；第 2 件智能体：67330000～67331999；
  - 第 1 件打到终局：67350000 + 500 i 派生。
- 下一个空位 **67400000**。

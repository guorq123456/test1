# 视野修正标签的候选：门的预注册（架构线程 2026-10-10 07:18Z 布置；写在候选做出来、任何门的对局之前）

**条件**：对手卡表已知（牌序、手牌未知）。

**起因**：M5（`README-m5.md`）里，最大 PP 和手牌按 G_end 定的价格明显高于 T 和现装模型；SEP 是模型给得比 T 和 G_end 都高。建造线据此做一个候选：
- 标签改成 L″ = L + Σ_r (price_G,r − price_T,r) · Δr，r ∈ {最大 PP，手牌张数，SEP}；
  - L 是第 1 步的标签；Δr 是这一对打法在 r 上的差（16 个 T 回合末的平均差，同 M5）；
  - 价格按半交叉拟合：一半的标签用另一半的价格（`m5/m5_halves.json`：只用训练开头、不含 end，按局号奇偶分半）。
- 然后重拟原版跳费龙镜像的回合末（ENDED）模型，其余照第 1 步候选的做法。ACT 模型不动。
- 候选的目录名和提交号由建造线定，开门前补在这里。

## 开门前的检查（在留出开头上；任一条不过就不开门）

用 `prices.py --pregate <候选的规格>`，在第 1 步的 179 个留出开头上（不含 end，505 对）：
1. **价格往 G_end 那边动**：候选的 ΔV 在 M5 的同一个回归量矩阵上回归。最大 PP 和手牌两项的价格都要高于现装模型在同样对子上的价格（G_end 给这两样的价格都高于模型）。看点估计。
2. **排序不变差**：和 ΔT 同号的比例（ΔT = 0 的不算，ΔV = 0 算一半），候选减现装不低于 −1 个百分点。
- 冒烟（候选 = 现装自己）：两边价格相同、同号率都是 79.0%（442 对，和第 1 步留出读数的 0.787 对得上）→ 第 1 条「否」→ 不开门。工具按预期工作。

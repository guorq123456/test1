## 结果和判定（2026-10-10 20:3xZ；本容器 3 个进程，svsim 32eb2db，936 秒；`analysis/gates/xprune-cross/gate_*.jsonl`、`gate_pooled.txt`、`cells.txt`、`log_*.txt`）

- **A = `mcts:196+plan+learned+phased+xprune=3:3:cost` 对 B = `level-strong`，12 格合并：50.0%**
  - `pooled.py` 按格分层逐对重抽 4000 次：**46.0%～54.0%**；CR +0（−38～+38）。
  - **(NI) 下沿 ≥ 46%：过，但正好压在线上。**
    - 下沿的精确值是 **0.4600**（552 / 1200）。每对得分是 0.25 的倍数，300 对的均值只能落在 1/1200 的格点上，第 100 小的重抽均值正好是 552 / 1200。
    - 按「≥」算成立。
    - 照记：pooled.py 换别的随机数种子（0、2～5）是 46.0%～46.2%；按格分层的正态近似是 45.99%～54.01%，差一点不到 46。判定照预注册的 pooled.py，算过；但这是压线过，没有余量。
  - **J85**（置信 80%）**→ 对**（压线）。
- **门内每决策毫秒比（12 格合起来）1.008**（A 79.56 / B 78.93），在带子里。各格从 0.887 到 1.191 不等，卡组不同剪枝的开销不同，只看合起来的。

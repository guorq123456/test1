# 用 Salem 自己的选择教评估器（cand-sp）：读法、门和第二读数的预注册（架构线程 2026-10-10 16:49Z 布置；写在建造线出任何数之前）

**条件**：对手卡表已知（牌序、手牌未知）。

**候选**（建造线做数据和拟合；目录名、提交号、智能体串、λ 网格开门前补在这里）

- 在 cand-kc 的目标上加一项偏好损失：「Salem 的回合末排第一」。λ 按留整局的交叉验证选。

## 1. 离线读法

**分折**
- **按整局分**：一局的所有回合在同一折，同一局的回合不跨在拟合和读数两边。
- **嵌套**：
  - 外层 5 折报数：Salem 的局按对局号排序，第 j 局进第 j mod 5 折；
  - 内层在外层的训练局里再按整局分 4 折，只用来选 λ。
  - 外层每折各选各的 λ，读数只在外层留出的局上算，所以报出来的准确率不受选 λ 的偏差影响。
- **λ 的选法**：在建造线给的网格上（须含 λ = 0），取内层交叉验证成对准确率最高的。并列时取较小的 λ。各折选到的 λ 照报。

**指标**
- **成对准确率**：一对是「Salem 的回合末 对 现装 1043 前 8 个里的一个」，模型给 Salem 的分更高算对，相等算一半。
  - 和 Salem 的回合末 `state_key` 相同的对照不算。
  - 在外层留出的局上合起来算。
- **自对局对比误差**：cand-kc 的留出验证集（val）上的对比均方误差，cand-sp 对 cand-kc 的比值。
- **区间**：按局重抽 2000 次（随机数种子 0），在外层留出的局上取百分位。准确率的差（cand-sp − cand-kc）在同一批对子上成对重抽。
- **分开报**：跳费龙镜像的局和其他对位的局各报一份（每份的局数、回合数、对子数、cand-sp / cand-kc / 现装三者的准确率）。只合在一起报不够。
- **对照**：同样的外层留出局上，cand-kc（λ = 0）和现装 ENDED 模型的成对准确率。
- **J75**（架构线程，置信 **40%**），两条都要成立，都看点估计：
  1. 成对准确率比 cand-kc 高至少 **5 个百分点**（跳费龙镜像和其他对位合起来）；
  2. 自对局对比误差变差**不到 3%**（cand-sp ÷ cand-kc < 1.03）。
- 照记：这项损失教的是「像 Salem」，不保证「赢得多」；Salem 也有失误。所以对局里的效果要看下面的门和第二读数。

# 新评估器有没有让 bot 在 Salem 的局面上更像他那样运营（架构线程 2026-10-10 14:26Z 布置；写在任何运行之前；只作描述加判断，不是门）

**条件**：对手卡表已知（牌序、手牌未知）。

**局面**：排序集里 |ΔG| ≥ 0.10 的 **33 个开头**（`ranking/rows.jsonl`；M4 的开头，ΔG 用 M4 / 复测的值）。

## 做法

1. **三个设置，都在最强档的算力下**，各从记录里的真实局面打这一回合 8 次（智能体自己确定化对手的手牌）：
   - 现装 `mcts:1043+plan+learned+phased`；
   - cand-kc `mcts:997+plan+learned+phased=cand-kc-ramp-ramp`（最强档门里配平的 N，门内毫秒比 1.028）；
   - cand-nl `mcts:913+plan+learned+phased=cand-nl-ramp-ramp`。913 = round(1043 × 162 / 185)，按强档门里两次配平的比例换算。建造线按每秒迭代估的是约 859，只作参考，不另校准。
   - 种子：第 i 个开头（M4 的号）用 67900000 + 100 i + r，r = 0～7；三个设置用同一批种子。
2. **给回合末打分**：每个回合末用 M4 同样的 G_end 打到终局，default 方向，双方 `mcts:100+plan+learned+phased`，**K = 32**。
   - 同一个开头的所有回合末用同一批 32 个种子：`direction_rollout(seed = 67950000 + 500 i)` 派生，所以彼此配对。
   - Salem 自己的回合末也用这批种子重打一遍。
   - 回合末按 `search.lethal.state_key` 去重，相同的回合末只打一次，结果复用。
3. **每个设置在每个开头的值** = 8 次回合末 G_end 的平均。

## 报什么

- 每个设置在 33 个开头上的平均 G_end，以及 Salem 回合末的平均 G_end。
- **差距缩小了多少**：差距 = Salem − 设置（33 个开头平均）；cand-kc、cand-nl 各自比现装缩小的比例 =（差距_现装 − 差距_设置）÷ 差距_现装。
- **和 Salem 回合末一样的比例**：每个设置 264 次回合末（33 × 8）里，`state_key` 和 Salem 的回合末相同的比例。
- 两两的差（cand-kc − 现装、cand-nl − cand-kc），区间按开头成对重抽 2000 次（随机数种子 0）。
- **J67**（架构线程，置信 **60%**）：cand-kc 的平均 G_end 高于现装（看点估计）。
- **J68**（架构线程，置信 **40%**）：cand-nl 的平均 G_end 高于 cand-kc（看点估计）。
- **另报**四道题：329、455、题 2（518）、题 3（445）每个设置的 G_end、出现最多的回合末、是否和 Salem 的一样。

## 机器和代码

- 本容器 3 个进程，svsim 建造线 afc85df（现装和 cand-kc 的行为和之前相同，cand-nl 是提速版）。不改 svsim 的代码，新写分析脚本 `opsgap.py`。
- 算力估计：打回合 792 次（33 × 3 × 8），每次约 2～4 秒；G_end 去重后约 300 个回合末 × 32 局。合计约 1.5 小时。

**怎么读**（照记，不改判定）
- 在这 33 个 Salem 的大差距回合上，新评估器没有让最强档的 bot 更像 Salem，平均 G_end 还略低（−0.02、−0.03，区间都含 0）。
- **题 2、题 3 是反方向的**：
  - 现装 1043 在这两题上都走对了（题 2 八次都是 Salem 的回合末；题 3 是另一个顺序、值相当的回合末，和 `README-gap.md` 第 1 件一致）。
  - cand-kc 997 和 cand-nl 913 在两题上 8 次都走同一条坏线（G_end 0.000 / 0.125）。
  - 建造线离线说 cand-kc 给这两题的回合末仍排对（0.508 / 0.298、0.517 / 0.373）。可搜索走出来的却是另一条线，说明问题不在回合末的打分，而在搜索过程中的评估（例如 ACT 模型和 ENDED 模型的配合，或中途局面的打分）。推断，没有检验。
  - 值得建造线拆一下：用 cand-kc、`mcts:997` 在题 2、题 3 上看根节点各走法的访问和价值，和现装 1043 比。
- 这和强档、最强档门里 cand-kc 赢棋（+2～+3 个百分点）不矛盾：门量的是整局的平均，这里量的是 33 个特意挑出来的、Salem 打得比 bot 好的回合。

# 200 次和 800 次搜索在一般对局里选得不一样的地方：第一步是哪一类（架构线程 18:12；只报数，不出候选、不开门）

**条件**：对手卡表已知（牌序、手牌未知）。

**问题**：J14 里「搜索次数不够」那一类（#2、#5、#9）都是多步连招：先用额外 PP 再出牌，或者出牌再超进化。这类局面在一般对局里多不多？200 次和 800 次选得不一样时，800 次选的第一步多半是哪一类？这个测量为 C3 之后选下一条线做准备：
- 如果不一致的大头是「用额外 PP」或「进化 / 超进化」开头的连招，就考虑做动作合并，例如把「用额外 PP 并出 X」算成一个根节点动作。这是搜索侧的改动，和 B 线的次数重分配不同。
- 如果比例很小，或者类别很分散，就不做。

## 方法（写在任何结果之前）

- **局面**：从联赛重跑 3000 局（`local/pairings-20261008` 的 `analysis/local-runs/league-after-20261008-part{1,2,3}.jsonl.gz`，v2s 对 v2s，四套比赛卡组）里抽。
  - 只取有配对模型的 11 个一方（同 `../c3-threat/`），每个一方 50 个，共 550 个。
  - 局面要求：主阶段，轮到这一方走，合法动作多于 1 个。
  - 先把 3000 局按固定种子 65400000 打乱，按顺序取，每局最多取 1 个局面。
- **搜索**：用现装第 22 版的强档 `mcts:N+plan+learned+phased`（代码 b9f2aca），N = 200 和 800，各 3 个种子。第 i 个局面、第 s 个种子用 65400000 + 10 i + s（200 次用 s = 0、1、2，800 次用 s = 5、6、7）。在分析线自己的容器里跑。
- **比较**：用 `search.mcts.action_key` 比走法。
  - 每个 N 取多数票（3 个里至少 2 个相同）；
  - 两个 N 都有多数、且多数不同，记「不一致」；
  - 有一边没有多数的，单独记。
- **报什么**：
  1. 不一致的比例（全部，和逐个一方）；
  2. 不一致时，800 次多数选的第一步属于哪一类：用额外 PP、进化 / 超进化、出牌、攻击、结束回合；
  3. 对照的噪声：同一个 N 的 3 个种子不全相同的比例。
- 种子库 65400000（下一个可用 65500000）。

## 结果（结果出来以后记的；`depth_disagree.py`，每个局面一行在 `rows.jsonl`，输出 `report.txt`；在分析线容器 b9f2aca 的检出上跑，4 个进程）

- 550 个局面，11 个一方各 50 个，编号 0～549 不重不漏。
- **200 次和 800 次多数票不一致：92 / 550（16.7%）**；有一边没有多数（3 个种子各不相同）的另有 8 个。
- 噪声对照：同一个 N 的 3 个种子不全相同的局面，200 次 7.8%，800 次 6.9%。所以 16.7% 明显高过同一 N 内部的噪声，不一致是真的。

**不一致时，800 次多数选的第一步**（预注册的分类）：

| 第一步 | 个数 | 占不一致的 |
|---|---|---|
| 用额外 PP | 3 | 3% |
| 进化 / 超进化 | 6 | 7% |
| 出牌 | 61 | 66% |
| 攻击 | 21 | 23% |
| 结束回合 | 1 | 1% |

**逐个一方**：连击妖三个一方最高（28%、24%、30%），跳费龙四个一方最低（6%～14%），机锋、旗皇在中间（12%～20%）。

**附加的交叉表**（不在预注册里，照记）：不一致时，200 次第一步的类别对 800 次第一步的类别。

| 200 次 \ 800 次 | 用额外 PP | 进化 / 超进化 | 出牌 | 攻击 | 结束回合 |
|---|---|---|---|---|---|
| 用额外 PP | 0 | 0 | 1 | 0 | 0 |
| 进化 / 超进化 | 1 | 1 | 5 | 2 | 0 |
| 出牌 | 1 | 4 | 42 | 13 | 1 |
| 攻击 | 1 | 1 | 13 | 6 | 0 |
| 结束回合 | 0 | 0 | 0 | 0 | 0 |

- 92 个不一致里 49 个两边是**同一类**，只是出的牌或打的目标不同。其中「都出牌、出的不同」42 个，最多。

**读法**（照预注册写在前面的标准）：
- 以「用额外 PP」或「进化 / 超进化」开头的不一致只有 9 / 92（10%），约占全部局面的 1.6%。**比例很小，按事先的读法，不做「用额外 PP 并出 X」「出牌并超进化」这类动作合并。**
- 不一致的大头是「出哪张牌、打哪个目标」（出牌 66%，攻击 23%，其中一半两边同类）。这是一般的搜索深度效应，类别分散在出牌和攻击上，不是某种特定的连招。
- 照记两个限制：
  - 第一步是「出牌」的，可能后面接超进化（像 J14 的 #5「出《正义》再超进化」）。只看第一步分不出来，所以「出牌接超进化」的连招有一部分藏在「出牌」那 66% 里。
  - 这里只量了「选得不一样」，没量「哪个更好」。800 次不一定更好；整体上 200 → 1600 次是 +47 ± 50 CR（J3）。

# 练习场说明（给选手）

版本：练习场 arena-1。写于 2026-11-22（主持方）。打法怎么写见 base-interface.md，怎么提交见 submit.md。

## 一、练习场里有什么

- **这一期池子的冻结副本**：每个成员冻结的卡组和打法，加上一个固定的 CR。另外还有**锚点**（池子外面固定的对手）。
- **你看得到的对手信息**：成员只有匿名编号、职业、相对 CR，和公开排行榜一样；锚点只有名字和职业。卡表、打法、是谁的、第几版，都看不到。
- 下面这条命令列出全部对手、这一期的时限，以及你已经打了多少局：

```
python -m ladder.arena field 练习场目录 --player 你的代号
```

## 二、一个「版本」

练习场里打的「版本」是一个目录，里面放：

- `strategy.py`
- `submission.json`：只要 `class`、`deck` 两项，别的可以不写。

每次跑之前，工具先用提交校验里读代码、查卡组那两条查一遍（见 submit.md 第三节），过不了就不跑。

## 三、能怎么打

### 1. 按池子的匹配打，估你的相对 CR

```
python -m ladder.arena ladder 练习场目录 --player 甲 --version 版本目录 [--replacing 你的成员编号] --games 600 --tail 300 --repeats 3
```

- 你的版本当候选，按池子自己的匹配规则对冻结副本打：只和 200 分以内的对手配对，没人就重抽。这和最终评测用的是同一个工具。
- 结果：相对 CR 的估计和区间。每个重复打 `games` 局，取最后 `tail` 局的平均 CR，减去池子的平均；区间按重复之间的差别算。
- `--replacing` 把你的某个成员换成这个版本，这个成员自己就不当对手了。
- **停住的重复**：你的 CR 走到离所有对手都超过 200 分，就没人可打了，这个重复会停在那里。它的读数只是界限：停在顶上的，至少有这么高；停在底下的，至多这么低。结果里会标出来。

### 2. 指定对手或职业打 N 局

```
python -m ladder.arena vs 练习场目录 --player 甲 --version 版本目录 --opponent 编号 --games 400
python -m ladder.arena vs 练习场目录 --player 甲 --version 版本目录 --class 龙族 --games 400
```

- 结果：胜率和 95% 区间。先后手各一半。用 `--class` 时，这个职业的成员轮流当对手。
- **比两个版本**：

  ```
  python -m ladder.arena vs 练习场目录 --player 甲 --version 新版本 --same-as 旧的那次的编号
  ```

  这会把那一次的局原样重打一遍：同样的发牌、同样的对手、同样的先后手、双方打法用同样的随机种子，只换你的版本。结果里有两版的配对差（百分点）和区间，还有「两版都赢」「都输」「只有新版赢」「只有旧版赢」各几局。真正提供信息的是结果不同的那些局。

### 3. 从你某一局的某个局面接着打

```
python -m ladder.arena resume 练习场目录 --player 甲 --run 那一次的编号 --game 那一局的编号 --decision K --version 版本A [--version 版本B] --continuations 50
```

- `K` 是你在那一局里做的第几个决定，从 0 数，`replay` 里有编号。
- 工具把那一局按原样重打到你的第 K 个决定，然后换上你给的版本接着打。
- 续打 0 用那一局原来的牌序和随机结果。续打 1～N 把双方都还没见过的牌序重新洗、以后的随机结果重新定；每个续打对每个版本都一样，所以两个版本可以一局一局地比。
- 结果：每个版本赢了几局。给了两个版本时，还有配对差和区间。
- 隐藏信息由工具保管，你看不到。
- 注意两点：
  - 续打时，双方的打法都是在那一步新建的，之前攒下的内部状态不带过来。
  - 续打的对局没有每步超时：打法卡住，整个续打就卡住。
  - 续打出来的局不能再续打，也不能回放（续打点之后重新洗了牌）：从原来那一局开始。

### 4. 看回放

```
python -m ladder.arena replay 练习场目录 --player 甲 --run 编号 --game 编号
```

- 给你自己那一侧在每个决定时看到的局面（和你的打法拿到的公开局面一样），加上双方的全部走法。
- 对手的走法照真人看到的给：对手打出、亮出的牌看得到；对手换牌只显示「换牌」，不显示换了哪几张。
- 不给对手的卡表、手牌、牌序，也不给种子。

## 四、局数、时间、种子

- 每期最多 2 万局。每一局都算，续打每个算一局。时限是每期 4 小时。要超过的那一次不跑。
- 种子只用你自己那一段调参种子，由工具替你管，不告诉你具体号码。要在同一批局上比两个版本，用 `--same-as`。
- 电脑上同一时间只跑一个人的对局，别人在跑时你的会排队。

## 五、结果放在哪

- 都在 `练习场目录/players/你的代号/` 下面：
  - `runs/编号/summary.json`：这一次的结果；
  - `runs/编号/games.jsonl`：每一局，你一侧的；
  - `runs/编号/replay-局号.json`：回放；
  - `count.jsonl`：你的局数账。
- 别的目录不是给你的，不要读（红线 5）。

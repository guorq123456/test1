## 2.1 打法接口（代码已写，待验收）

- 代码：ladder/interface.py（`PlayerStrategy`）。给选手看的说明：public/base-interface.md。
- 能改的点：对手卡表的猜测、换牌、估值的数值或整个估值、排除某些走法、根节点的走法偏好、每步的搜索设置（次数、探索系数、估值尺度、深度、偏好权重）、斩杀搜索开关。都只拿到公开局面或按自己猜测抽出来的局面。
- 没开放的：换掉搜索本身（ISMCTS）、对手回合的模拟（reply）、训练过的模型（A12）。理由：开放搜索本身就等于开放任意代码，提交校验管不住；reply 和模型牵涉 A12。要不要开放，等起点测量（2.6）以后看选手卡在哪里再说。
- 验收（规划：「默认打法只用接口就能完整复现」）：不改任何点的子类、每个点都手写成默认做法的子类，和默认打法逐个决策比。单元测试 3 局；复现检查 tools/check_interface.py 40 局、2588 个决策，两种子类都 40 局全部逐个决策一样（probe/interface-check-2026-11-22.json，LD-26）。都在云端容器上跑。

## 2.3 提交入口和提交校验（设计）

一次提交 = 成员编号（新卡组时空着）+ 卡组代码（卡组期）或打法模块（策略期）+ 规划要求的文字（改了什么、预期差多少、为什么）。主持方收下后回一张回执：收下 / 拒收 + 每条理由，进提交台账（只增不改）。

查什么：

| 查 | 怎么查 | 拦得住吗 |
|---|---|---|
| 卡组合法 | 40 张、同名最多 3 张、本职业 + 中立、卡池以模拟器为准（A7） | 拦得住 |
| 卡都有脚本 | runner.unscripted：有效果却没脚本的卡会按白板打 | 拦得住（拒收并列出卡名） |
| 名额 | 每人最多 7 个成员、同一卡表最多 2 个、每个卡组期每人最多 2 副新卡组（池管理器已有） | 拦得住 |
| 打法是 `PlayerStrategy` 的子类 | 载入后检查 | 拦得住 |
| 只 import 允许的模块 | 静态检查（语法树）：允许 ladder.interface、ladder.base、svsim（svsim.learn、svsim.tools 除外：它们能载入训练好的模型）、math、random、collections、itertools、functools、dataclasses、heapq、numpy | 拦得住直接的 import |
| 不碰文件、网络、别的进程、调用栈 | 静态检查禁用 open、eval、exec、compile、`__import__`、globals、vars、getattr 拿双下划线属性、inspect、gc、sys、os、subprocess、socket、ctypes、threading、time 等；运行时在单独的进程里载入，载入后装 Python 审计钩子（PEP 578），文件、网络、子进程事件一律报错 | 大部分拦得住；**拦不住的**：同一个 Python 进程里有决心的代码总能绕过（审计钩子不是安全边界）。所以还靠第三条：抽查 |
| 确定性 | 同一种子打 2 局，再按日志逐个决策重放（replay.py 已有） | 拦得住「不确定」本身 |
| 算力 | 和默认打法同一批对局比每步平均 CPU，超过 1.08 倍先警告（检验时超过就判无效，A25） | 检验时拦得住 |
| 冒烟 | 对默认打法打 10 局（调参种子），不崩、不超时、不走非法步 | 拦得住 |

抽查：主持方每期随机抽几份提交读代码，读到违规的按规则处理并记账。

## 2.4 练习场（设计）

- 对手：池子当期的冻结副本（每个成员冻结的卡组 + 打法 + CR）和锚点。选手看到的对手只有匿名编号、职业、相对 CR（和公开排行榜一样）。
- 打法：
  1. 按池子的匹配规则打（和冻结池评估器一样，S2、S3：200 以内才配对），给出自己的相对 CR 估计和区间；
  2. 指定对手（匿名编号）或指定职业打 N 局，给胜率和区间；
  3. 从自己某一局的某个决策点续打：用原种子重演到那一步，换自己的新版本接着打（对手和随机结果照旧），给结果。
- 种子：只发调参段 87400000～88399999，每人一个不重叠的子段，用到哪记到哪。
- 回放：只给选手自己那一侧看得到的东西（公开局面），对手卡表、手牌、牌序一概不给。对手亮过的牌照常看得到（真人也看得到）。
- 计数：每人每期局数（上限 2 万局）、用时（临时限时每期 4 小时），到点停。
- 算力：Salem 电脑上 11 个工作进程，所有选手共用，轮流分配（D2）。选手时段里电脑只跑练习场。
- 隐私：别的选手的卡组和代码在电脑上跑，但选手只拿到结果和自己一侧的回放。不同选手的练习记录互不可见。

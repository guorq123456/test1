# 对手手牌推断（`+infer=ALPHA[:TAU]`，默认关）：抽样准不准（2026-10-08）

代码 7343351：`svsim/search/infer.py`、`core.view.determinize` 的加权抽样、`svsim/tools/infer_check.py`。

**做法：**
- 在我方每回合的第一次决策时，对对方「手牌 + 牌库」里的每种牌检查两点：
  - 用它上回合剩下的 PP 付得起，而且可以合法打出；
  - 从对方视角，用搜索自己的评估器算，「打出」比「空过」高 ≥ TAU。
- 两点都满足的牌，权重设为 ALPHA；然后按权重无放回地抽对方手牌。
- engine 核对：对方的 `pp` 在我方回合保留它上回合剩下的值，只有 `engine._start_turn` 会把它补满，`_end_turn` 不动它。engine 没有改。

**指标：** 抽出的手牌和真实手牌的重合比例（同种牌按真实张数封顶），每个决策点抽 150 次（Salem 局 300 次）。ALPHA=1 就是现在的均匀抽样。

## 个案

两处个案都没有触发：

- **1791304981889**（Salem 点名的 bot 第 7 回合，全局第 14 回合）：Salem 在 bot 第 5～7 回合前都把 PP 用光了（0/7、0/9、0/10）。
- **1791305120171 第 12 回合**：bot 上一回合 9/9 用光（架构线核对）。

这两步属于「从对方实际打了什么、留了几张去推」那一类，便宜版覆盖不到。

## 代价与结论

- **代价：** 每回合约 1.0 ms，232 个点平均。
- **结论（架构线 14:40Z）：** 先不开对打门。重合度只高 2% 左右，300 对分辨不出；本机算力排给 B1 / B2 的四道门。`+infer` 留在代码里，默认关，记作旁证。

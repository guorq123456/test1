# 搜索 A：没换上第 10 弹卡，是新卡不强还是很少试（不打新对局）

条件：对手卡表已知（牌序、手牌未知）

架构线 10-29 10:33Z 问：A 前 3 轮接受了 5 次改动，一次都没换上第 10 弹的卡。这是「新卡确实不强」，还是「搜索很少试新卡」？

只用 A 已有的 deals.jsonl 和 changes.jsonl，不打新对局。数字见 `results.md`，每个变体一行在 `variants.jsonl`，脚本是 `exploration.py`。

## 怎么拿到每个变体的卡表

- A 跑过的每个代码版本（b5985e4、089b688、86bb1d43、2d7e5043、37f84510）都在每个职业开始前把随机数设成 `Random("84801000:轮:职业序号")`，然后先抽 8 个变体。
- 所以用上一轮末尾 state.json 里的现任卡表（槽位顺序也对），按同样的 `variant()` 重放，就能拿回第 1～3 轮全部 168 个变体。
- 核对：
  - 第 2 轮巫师起的记录带卡组代码。96 个变体的代码逐个对上，0 个不符。
  - 21 步减半的胜者（changes.jsonl 里的换下 / 换上）都在重放出的变体里找到了，0 个找不到。

## 结果（第 1～3 轮）

**(a) 试得少吗？不少。**

| | 变体 | 换上至少一张第 10 弹卡 |
|---|---|---|
| 第 1 轮 | 56 | 11（19.6%） |
| 第 2 轮 | 56 | 16（28.6%） |
| 第 3 轮 | 56 | 17（30.4%） |
| 合计 | 168 | **44（26.2%）** |

- 可选卡池（本职业 + 中立、有脚本、非衍生）里，第 10 弹卡占 14.2%。
- 一个变体换 1～3 张，所以「至少一张是新卡」的期望占比比卡池占比高。用同样的 `variant()` 从同样的现任各随机抽 400 次，期望是 **28.5%**。
- 实际 26.2%，差 −0.7 个标准误。搜索按卡池比例在试新卡，没有少试。

**(b) 试了以后表现如何？和别的变体一样。**

减半第 0 段里，所有变体在同一批 28 个发牌上对现任：

| | 变体数 | 平均配对差 |
|---|---|---|
| 含第 10 弹卡 | 44 | −2.2% ± 0.8% |
| 不含 | 124 | −1.9% ± 0.5% |
| 按换卡张数分层后的差（含 − 不含） | | **−0.2% ± 0.9%**（95% 区间约 −2.0～+1.6） |

- 两组都略负：随机换 1～3 张，平均会让比赛卡表变差一点。
- 有没有新卡，差别在 ±2 个百分点以内，看不出来。
- 第 0 段所有变体打同一批发牌，没有减半筛选带来的偏差，所以只用第 0 段。

**(c) 走到哪一步**

|---|---|---|---|---|---|---|
| 含第 10 弹卡 | 44 | 22（50%） | 9（20%） | 4（9%） | 3 | 0 |

- 含新卡、进了复核的 3 个：

- 另有第 1 轮皇家（诺·莱芙）是减半胜者，但没胜过现任，没进复核。

## 读法

- **不是「很少试」**：新卡出现在变体里的比例和随机抽卡的期望一致。
- **也说不上「新卡不强」**，准确的说法是：单张新卡随机塞进旧比赛卡表，平均和单张旧卡塞进去一样，不好也不坏；能分辨的差在 ±2 个百分点以内。
- **A 的设计看不到的**：第 10 弹的证据机制要好几张证据卡凑在一起才转得起来。A 每次随机换 1～3 张，几乎凑不出一整套，而且起点是换包前的卡表。所以 A 只能回答「单张新卡能不能挤进旧卡组」，回答不了「新卡组能不能打」。
  - 后一个问题由搜索 C 回答：它从随机卡组起步，六成是新卡，C 和孪生 Cg 都接受过新卡。
- 只看了第 1～3 轮。A 跑完 10 轮后可以用同一个脚本重算（`ROUNDS` 改成 1～10，state.json 用各轮文件夹里的）。

## 为什么要对照

只拿 bot 的名单去比天梯，对上了也说明不了多少：七个职业里取前三，碰巧对上的机会本来就不小。
对不上，也分不清是评分的 bot 有偏，还是搜索太弱。
所以要有一份「不费脑子」的对照名单，bot 必须明显比它更接近天梯，才算学到了东西。

## 指标（比对时 Salem 提供天梯一侧：每个职业的主流卡表，和职业强弱排名）

1. **重合张数。** 每个职业，拿 bot 名单里这个职业排名最高的一副，和天梯这个职业最主流的卡表比，数两副共有多少张（同一张卡按较少的份数算）。对照名单同样算一遍。
   - 通过线：7 个职业里至少 5 个 bot 比对照重合得多，而且 7 个职业平均多 3 张以上。
2. **职业排名。** bot 名单按各职业最强一副的循环赛得分给职业排名；对照名单用同样的循环赛排名。两份排名各自和天梯的职业排名算 Spearman 相关。
   - 通过线：bot 的相关高于对照。
3. **新卡张数。** bot 的 T1 卡组每副平均带几张第 10 弹的卡，和天梯 T1 卡组比（计划文件判断 12）。
4. **像不像。** Salem 看 bot 的每副 T1 卡组，判断它是不是天梯上某个 T1 套路（是 / 否）。Claude 组同样判一遍。
5. **模拟器里互打（只在所有名单都冻结之后）。** bot 组和三个 Claude 子组的卡组放在一起打一次循环赛，便宜 bot 和强档评分各打一遍；结果按「bot 对 g1、bot 对 g2、bot 对 g3」三对分别报，子组之间的对局也一起报。
   - 注意：bot 组的卡组本来就是对着便宜 bot 挑出来的，便宜 bot 打的这一遍偏向 bot 组；两遍结果不一致时，以强档那遍为准，并把不一致本身记下来。

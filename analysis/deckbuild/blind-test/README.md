# 第 10 弹盲测：事先登记（2026-10-29，在 Salem 比对之前）

Salem 10-29 说：过几天他会拿 bot 构筑出的强势卡组，和实际天梯的强势卡组比一比，看差多少。
这个文件在比对之前写好并提交，提交时间证明下面的对照和指标是事先定的。
写的时候，没有任何一条线查过第 10 弹环境的卡组、强度排行或天梯数据。

## 为什么要对照

只拿 bot 的名单去比天梯，对上了也说明不了多少：七个职业里取前三，碰巧对上的机会本来就不小。
对不上，也分不清是评分的 bot 有偏，还是搜索太弱。
所以要有一份「不费脑子」的对照名单，bot 必须明显比它更接近天梯，才算学到了东西。

## 对照名单

换包前的比赛卡表，每个职业取一副，退环境的牌按费用就近换成合法的牌（随机挑）。
就是搜索 A 起步时用的七副卡组，卡组代码在 control.txt。
这份名单代表「什么都不学，只把上个版本的强卡组补一补」。

## 指标（比对时 Salem 提供天梯一侧：每个职业的主流卡表，和职业强弱排名）

1. **重合张数。** 每个职业，拿 bot 名单里这个职业排名最高的一副，和天梯这个职业最主流的卡表比，数两副共有多少张（同一张卡按较少的份数算）。对照名单同样算一遍。
   - 通过线：7 个职业里至少 5 个 bot 比对照重合得多，而且 7 个职业平均多 3 张以上。
2. **职业排名。** bot 名单按各职业最强一副的循环赛得分给职业排名；对照名单用同样的循环赛排名。两份排名各自和天梯的职业排名算 Spearman 相关。
   - 通过线：bot 的相关高于对照。
3. **新卡张数。** bot 的 T1 卡组每副平均带几张第 10 弹的卡，和天梯 T1 卡组比（计划文件判断 12）。
4. **像不像。** Salem 看 bot 的每副 T1 卡组，判断它是不是天梯上某个 T1 套路（是 / 否）。

## 我事先给的预测

- 指标 1，bot 通过：把握 0.2。审查报告指出 bot 的卡组是「随机卡组加几处修补」，每副 27～31 种不同的卡；对照是成型的旧卡组，很多牌换包后还能用，所以对照多半重合得更多。
- 指标 2，bot 的相关高于对照：把握 0.45。
- 指标 3，bot 的 T1 平均新卡张数少于天梯 T1：把握 0.75（判断 12）。

## 名单本身的限制（比对时一起看）

- 卡组的强弱由便宜 bot（手写评分的一回合搜索）打出来的胜率决定。它看不见「先铺垫、后兑现」的打法，证据机制正属于这种。
- 所有对局都是「对手卡表已知（牌序、手牌未知）」。
- bot 从没和人或外部 bot 打过。
- 最终名单冻结时另行提交，并写明用的是哪些搜索的结果。

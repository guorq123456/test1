## 2. 留出误差（开跑前写死）

- **局面**：留出 5000 局里的每个回合末。即该回合 EndTurn 之前的局面补上 `after_end_of_turn`；视角是刚结束回合的那一方。
- **标签**：这一方的终局结果，赢 1、输 0、平 0.5。
- **主指标：Brier 分数** = 所有留出回合末上 (p − y)² 的平均，每个回合末等权。
- **辅指标：log-loss**，p 截在 [10⁻⁶, 1 − 10⁻⁶]。
- **并排报的 7 个模型**，在同一批留出局面上：
  - 价值网络 10³ / 10⁴ / 10⁵；
  - 线性重拟 10³ / 10⁴ / 10⁵（现装特征集，对终局胜负拟合，配方由建造线定、开跑前补写）；
  - 现装线性评估器（v2skx 在该对位读到的回合末模型）。
- **概率怎么来**：
  - 对胜负训练出来的模型（价值网络、线性重拟）直接用它的输出概率。
  - 现装评估器的输出不是概率，用 p = σ(a · z / SCALE + b)；a、b 在 10⁴ 训练集的回合末上做一维逻辑回归拟合，不碰留出集。也照报原样的 σ(z / SCALE)。
- **另报**：
  - 常数 0.5 的 Brier（无平局时就是 0.25）；
  - 每个模型的 **skill = Brier(0.5) − Brier(模型)**，即超出常数预测的那部分。
- **区间**：按留出对局整局重抽 2000 次（随机数种子 0）。两个模型的差在同一批局面上成对重抽。
- **分段照报**（只作描述）：第 1～5 回合、第 6～10 回合、第 11 回合起。

## 3. J90 的判法（架构线程问阈值合不合理；**我的改法提案，待架构线程定**）

- **规格原文**：价值网络 10⁴ → 10⁵ 局，留出 Brier 至少再降 10%（相对），置信 40%。
- **我的看法：相对 Brier 降 10% 几乎不可能。**
  - 终局胜负的标签噪声很大：现装评估器的 Brier 是 0.207，只比常数 0.5 的 0.25 好 0.043。
  - 剩下的 0.2 里绝大部分是不可约的。很多局面本来就胜负难料：第 1～5 回合，现装只比常数好 0.016。
  - 10⁴ 的网络假设在 0.20 左右，再降 10% 就是到 0.18，单是 10⁴ → 10⁵ 这一步就要降 0.02。这几乎等于现装评估器比常数好出来的全部，也就是要把 skill 再翻一半。
- **提案：按超出常数预测的那部分算。**
  - **J90 改成：skill(10⁵) ≥ 1.10 × skill(10⁴)，看点估计**；skill = Brier(0.5) − Brier(模型)，同一批留出局面。
  - 按上面的量级（skill 约 0.05），10% 相当于 Brier 再降约 0.005。
  - 5000 局留出、约 10⁵ 个回合末，同一批局面上成对比的差，标准误估计在 0.001 量级，这个变化量得出来。
  - 区间照报（按整局重抽），判定看点估计，同以往的 J。
- 架构线程不改就照规格原文判；改就照提案判。**开跑前定下来，写在这一节下面。**
- **定了（架构线程 10-15 17:32Z，数据前改定）：J90 = skill(10⁵) ≥ 1.10 × skill(10⁴)，看点估计，skill = Brier(0.5) − Brier(模型)，置信仍是 40%。** 原文是「留出 Brier 相对降 10%」。理由：结局标签噪声大，相对降 10% 几乎要吃掉现装评估器比常数好出来的全部。

## 核对：搜索里哪些局面由网络打分（10-15 21:1xZ，`leaf_probe.py`，种子 71000000～71000004，10 局，只看搜索内部）

### 评法（本线定，判线以这一版为准）

- **决策点**：留出片里每个 MAIN 阶段、`search[i]` 不是 None、Σvisits > 0 的决策。
- **按 action_key 合并**：
  - 记录里同一个 action_key 的几个合法走法（例如手里两张同名牌）各记一份同样的访问数，搜索里它们是同一个子节点。所以按 `search.mcts.action_key` 合并成一个走法。
  - 合并后：π_k = 该键的访问数（只算一次）÷ 各键访问数之和；先验 p_k = 同键各走法的概率之和（和搜索里 `_root_prior` 的加法一样）。
  - 主口径：合并后至少 2 个键的决策。建造线若按原始合法走法报（不合并），本线两种都算、都写出来，**判线用合并口径**。
- **三档**：
  - **回合开始**：这一回合该行动方的第一个 MAIN 步（同 `learn.policy.decisions` 的 start：不管这一步是不是搜索下的，回合内第一个 MAIN 步才算）；
  - **回合中**：其余决策；
  - **结束还是继续**：在全部决策上看"访问最多的是不是结束回合"这一个二分问题。报 p(结束回合) 的 AUC，和"先验首选是结束回合"的混淆表。展开顺序把结束回合放最后，所以它永远判"继续"。
- **指标**（每个决策算一个数，再对决策取平均）：
  - **首选一致率**：A = 访问最多的键的集合（并列都算），B = 先验最高的键的集合。这一个决策得 |A ∩ B| ÷ |B|，相当于先验并列时随机挑一个。
    - 均匀分布：|A| ÷ n。
    - 展开顺序：B = `ISMCTS._options(state, me, None)` 的第一个键，就是这个选手串的搜索在根节点第一个展开的走法（含 reserve / veto / prune 和 `_rank` 排序）。
  - **KL(π‖p)**、交叉熵 H(π, p)：自然对数，p 下限截到 1e-12。展开顺序不是分布，不算 KL。
  - **前两名覆盖**：先验前两个键（并列按键在合法走法里第一次出现的顺序）上的 π 之和。展开顺序取前两个展开的键。均匀分布取期望 2 ÷ n。
- **区间**：按局整块重抽（74100038 是 500 局，71600018 是 1000 局），2000 次，`numpy.random.default_rng(0)`，取 2.5% / 97.5% 分位。差值和比值都是在同一次重抽里算两边，再取分位。

### 过线标准（每套牌、每版先验分别判）

- **O1-1 首选一致**：新先验 − 展开顺序，**下沿 ≥ +15 个点**。
- **O1-2 KL**：KL(π‖新先验) ÷ KL(π‖均匀)，**上沿 ≤ 0.70**（比均匀至少降 30%）。
- **O1-3 分档不伤**：回合开始、回合中两档各自，新先验 − 展开顺序的首选一致**下沿 ≥ 0**。
- **O1-4 跳费龙不低于旧头**（只跳费龙）：首选一致新 − 旧**下沿 ≥ −1 个点**，并且 KL 的点估计新 ≤ 旧。
- **一套牌过线** = 这套牌上至少一版先验 O1-1 ～ O1-3 全过（跳费龙再加 O1-4）。两版都过时，取留出 KL 低的；两版 KL 差不到 0.005 nats 时取冻结版（少维护一个主干）。
- **过线的那套牌**才考虑 B 档（每个节点 PUCT，替换 UCB1 的探索项，开关默认关、关时逐位相同）。B 档上门另行登记，等算力时扣掉先验开销。没过线的那套牌不开 B 档。
- **只报不判**：交叉熵、前两名覆盖、结束回合 AUC 和混淆表、按原始合法走法的口径、连击妖第 2 代留出 72800038（若它不在训练集里）。
- 照记：旧头当年离线一致率不低，对局仍是 H0（"从同一个搜索蒸馏出来，只会让它更像自己"）。所以离线过线只是开 B 档的门槛，不说明棋力。B 档用的搜索次数比 200 少（约 110～120），先验等于把 200 次的分配教给更少次数的搜索，这是和旧头不同的地方。

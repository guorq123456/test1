# 对照门：跳费龙对旗皇，不加特征的重拟合（B′）对现装

**条件**：对手卡表已知（牌序、手牌未知）。

**为什么开**：这一格三道加特征的门都明显比现装差：
- C2（加 hand）：60400000 是 41.0%，62200000 是 43.7%；
- C3 6 维（加 board）：62500000 是 43.0%。

加的特征完全不同，幅度却相近。我（c3-threat 第七节第 3 条）、协调线、架构线程都想到了同一个更省的解释：这一格的伤来自「重拟合 / 数据」本身，不是哪个特征。这道门就是查这个。

**门**（RC 70ba67e，代码 999ec27）：
- A = `mcts:201+plan+learned+phased=cand-bprime-ramp-t-pirate-t`。B′ 不加新特征，和 C2、6 维 C3 用同一份数据、同一种留出。
- B = C = `level-strong`，`--versus level-strong`，定长 300 对，种子 63700000～63700299，300 个种子逐个核过。
- 输出 `ramp-t_pirate-t_bprime.jsonl`（RC 文件复制在这里）。

**读法**：架构线程 16:38 发给 RC 时写的，在结果之前。我在 `../../seed-banks.md` 的登记和这份 README 是结果出来以后补写的，照记。
- B′ 的 LB(A − B) < 0：这一格的伤来自重拟合 / 数据本身。C2 两库和 6 维 C3 的三个负数不能当作特征之害；J9 的异质性去掉这一格重算；c3-threat、refit-200 README 加更正。
- B′ 的区间含 0：「特征本身在这一格有害」的读法保留。

**结果**（`../../oracle-hand/pooled.py` 复算，和 RC 一致）：
- **一对得分 49.5% ± 2.8%（46.7%～52.3%），A − B = −0.5 点（−3.3～+2.3），CR −5（−32～+22；稳态式 −4）。**
- 每搜索决策毫秒 A ÷ B = 1.004，算力匹配。

**正式判定：B′ ≈ 现装（区间含 0）。重拟合本身没有伤这一格。「特征本身在这一格有害」的读法保留，J9 的异质性不去掉这一格重算。**
- 我在 c3-threat 第七节第 3 条提的「伤害来自重拟合本身」被这道门否定了，照记。

**这一格拟合数据的核查**（架构线程 16:38 ①；读模型文件里记的 `info` 和数据文件，没有重新拟合）：
- **数据和视角**：
  - 数据文件 `data/pairings-20261008/pirate-t_ramp-t.jsonl.gz`（`local/data-pairings-20261008`）是 2000 局。每局的 `names` 是 `["ramp-t", "pirate-t"]`，文件名里两套牌的先后不代表视角。
  - 模型按 `--matchup ramp-t-pirate-t` 取跳费龙一方的局面，模型文件里记的是 deck = ramp-t、opponent = pirate-t。
  - 标签没有翻：ended 的拟合准确率现装 0.704、B′ 0.706。翻了会低于 0.5。
- **现装和 B′ 是同一份数据、同一种形式**：
  - 现装 ended：16226 个局面，数据 `C:\claude\svsim-data\pirate-t_ramp-t.jsonl`（本机 Windows 拟的），version 2，77 个系数，没有额外特征。
  - B′ ended：14749 个局面，version 2，77 个系数。留出表里这一格 ended 的留出局面正好 1477 个，14749 + 1477 = 16226，和现装逐个对上。所以是同一份数据去掉行号 % 11 == 0 的 182 局。
  - 建造线 16:49 补核：同一个文件，解压后 sha256 `f8f72e89…c992`，就是现装 `info` 里记的那份。代码和超参也相同：version 2、线性、2500 次迭代、L2 = 1e-3、单调约束相同、STOCK 置零。
  - 平台差可以忽略：建造线在云端用全量数据重拟过（C2 推广时的「复现现装」），ended 系数最大差 1.3e-11，act 7.2e-4。v2s 只用 ended。
  - 所以实质差别只有一处：B′ 少了 1/11 的局（少 9%）。这道门说明这一处不伤棋力。
- **留出切分**：C2、6 维 C3、B′ 用的是同一个切分（三个模型的局面数都是 14749）。
- 所以这一格的数据、视角、切分都没有问题。伤害出在加的特征上，而且 hand、board 两种特征都会伤。它们为什么伤，仍是开放问题。

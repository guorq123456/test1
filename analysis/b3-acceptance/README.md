**补充：这一格里 Salem 用点的 9 个回合是什么样**

这一格是"A 档在手、够不着"。9 个回合全在他自己的第 4～5 回合，也就是刚解锁进化的时候。进化的目标是：
- 佐伊（5费 5/5）7 次；
- 宣扬的龙人（2费 2/1）1 次；
- 露莉亚（2费 1/1）1 次。

当时手里都有正义、班德或金银。所以在这一格里，他刚解锁时先把场上的普通随从进化掉，往后的回合才留点给 A 档。要学"这一格里什么时候用"，关键变量很可能是"解锁后第几回合 × 场上有没有能打的普通随从"。

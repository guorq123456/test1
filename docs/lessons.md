## 做事的规矩（流程，不是打法）

| 编号 | 规矩 | 为什么 |
|---|---|---|
| P-01 | 预注册先写预测再跑；偏离预注册的地方在结果里单列「偏差」 | PRIOR.md、ROUND2.md 的做法，论文的 G4 |
| P-02 | 每份门控报告写「挑选种子库 / 确认种子库 / 结论只认确认库」 | 见 gate-report-template |
| P-03 | 训好的网要记模拟器提交号和规则哈希；规则文件改过的模型标「待复测」，herogate、deckgate 默认拒绝（`--allow-stale` 放行并打印）；没登记的旧模型只警告 | 论文的 G2；11-02 落地：svsim/learn/provenance.py，`python -m svsim.learn.provenance list` 查状态 |
| P-04 | Salem 的真实对局永不进搜索、自对弈、训练；只用来查模拟器和给他看分歧 | 他定的 |
| P-05 | 职业卡表只做对比，永不进搜索和训练 | 他定的 |
| P-06 | 容器里的长任务用 harness 跟踪的后台运行，不用 setsid；PC 上最多一半 CPU、不占 CPU0、低优先级 | 容器回收两次杀过任务；Salem 10-31 的限制 |
| P-07 | `pkill -f` / `pgrep -f` 会匹配到自己，按 PID 杀和等 | 踩过两次 |
| P-08 | 给 Salem 的结论用人话：中文职业名、胜率用文字、不写哈希和分支名 | 他说了七次 |
| P-09 | 等算力：X 与基线每决策 CPU 之比超过 1.08 时，按 round(N / 比值) 重跑一次；带先验的网有固定开销，重跑后比值常在 1.1～1.2，两组互比时把两边的比值都写出来 | PRIOR.md、ROUND2.md 的做法 |

# 规则摘要（面向引擎实现）

> 整理日期 2026-10-05。游戏版本 v1.9.11，最新卡包为第 9 弹《复苏的阿兹弗特》。
> 术语使用官方简体中文词汇表的译名（来自 `/web/System/glossaryList`，请求头 `Lang: chs`）。

**来源标记**
- **[官方]**：官网规则页、官方词汇表接口、官方公告。
- **[Q&A]**：官方卡牌数据库里的单卡裁定（`questions` 字段，共 120 张卡 165 条）。
- **[社区]**：主要是日文 wiki「おんJシャドビヨ部 · シャドバWBの仕様」（2026-09-06 更新），以及 Game8 / GameWith。
- **[未确认]**：没找到可靠来源。

每条规则后的 ✅ 表示骨架已经实现，⬜ 表示待实现。

## 1. 对局准备
- 牌组正好 40 张，由一个职业的牌加中立牌组成；同名卡最多 3 张。[官方] ✅（合法性检查 ⬜）
- 主战者生命值 20，也是上限。部分效果会改变上限。[官方] ✅
- 随机决定先手。双方起手各 4 张。[官方] ✅
- **开局重新抽取**：可以换掉任意张，只能换一次。换下的牌先放到一边，抽完新牌再洗回牌组，所以不会抽回同一张实体牌。[官方] ✅
- 双方每个回合开始都抽 1 张，**先手第 1 回合也抽**；后手不会多抽。[官方] ✅
- **后手补偿**：额外能量点；进化和超进化各提前一个回合解锁（见 §3）。[官方] ✅
- 手牌上限 9。手牌满时抽到或加入的牌会被销毁，墓场 +1，而且不触发"抽牌时"能力。[官方][Q&A] ✅
- 战场上限 5（随从和护符合计）。战场满时召唤无效；被召唤后放不下的牌不会增加墓场数。[官方] ✅
- 主战者区域上限 5（纹章和信仰合计），同名纹章不能重复。[官方] ⬜
- 需要从空牌组抽牌时判负。[官方] ✅
- 一个效果让双方主战者同时归零时，**回合玩家判负**。[Q&A] ✅
- 回合时长：可以进化之前约 60 秒，之后约 75 秒。[官方]（模拟器不计时）
- 回合上限：[未确认]。初代是第 40 回合双方判负；引擎用 `max_turns` 兜底。

## 2. 能量点（PP）
- PP 上限从 0 开始，每个己方回合开始时 +1（最多 10），然后回满。[官方] ✅
- **涨 PP**（"能量点上限 +1"）：新增的这一点是空的，下个回合才能用。[社区] ✅（`gain_max_pp`）
- **回复能量点**：最多回到当前上限；额外能量点生效的回合，上限视为"上限 + 1"。[Q&A] ✅（`recover_pp`）
- **额外能量点**（只有后手有）：
  - 按下后本回合 PP +1，可以超过上限（上限 10 时能到 11）。[官方][社区] ✅
  - 用过之后，在己方第 6 回合开始时刷新，所以一局最多用两次；没用掉的不会叠加。[官方] ✅
  - 回合结束时如果还剩至少 1 点 PP，这次使用自动作废、不消耗。[社区] ✅
  - 不计入觉醒：觉醒只看 PP 上限。[社区]
- **觉醒**：PP 上限 ≥ 7。[官方] ⬜

## 3. 进化与超进化
- 双方各有 2 个进化点（EP）和 2 个超进化点（SEP）。[官方] ✅
- **解锁回合**（按己方回合数计）[官方] ✅

  | | 进化 | 超进化 |
  |---|---|---|
  | 先手 | 第 5 回合起 | 第 7 回合起 |
  | 后手 | 第 4 回合起 | 第 6 回合起 |

- 每回合只能用点数进化 1 次，进化和超进化二选一。效果引起的进化不消耗点数，也不受次数限制。[官方] ✅
- **进化**：+2/+2；登场当回合就可以攻击随从；已经进化的随从不能再进化。[官方] ✅
- **超进化**：+3/+3（不在 +2 的基础上叠加）；登场当回合就可以攻击随从。另外：
  - **己方回合内**不会被能力破坏，受到的伤害变为 0。对手回合内没有这个保护。[官方] ✅
  - **击退**：攻击并破坏被攻击的那个随从时（不论是交战伤害还是攻击时能力造成的），对敌方主战者造成 1 点伤害。这一下在谢幕曲之前结算。[官方][Q&A] ✅
  - 超进化的随从也算"已进化"。
- 进化加成按普通增益处理，和其他身材修改按发生顺序叠加。[Q&A] ✅
- **能力触发**：
  - 用点数进化或超进化时触发"进化时"；用超进化点时，还会在之后触发"超进化时"。[官方] ✅
  - 卡面写"本随从进化时"的能力，任何方式的进化都会触发。[社区] ⬜
  - 被效果超进化（比如被别的牌超进化）时，获得数值和保护，但不触发"进化时"和"超进化时"。[Q&A] ✅
- 带屏障的超进化随从，攻击或被攻击时屏障也会消失，即使伤害已经是 0。[Q&A] ✅（引擎按"任何一次受伤事件都击破屏障"实现）

## 4. 交战
- 随从从登场后的下一个回合起，每回合可以攻击一次。[官方] ✅
- **疾驰**：登场当回合可以攻击随从和主战者。**突进**：登场当回合只能攻击随从。[官方] ✅
- 护符不能攻击，也不能被攻击；主战者不会攻击。[官方] ✅
- **守护**：只要己方场上有守护随从，敌方随从就不能攻击己方主战者和没有守护的随从。如果守护随从同时有潜行或威慑，就不算守护。[官方] ✅
- **威慑**：不能被攻击。**潜行**：不能被攻击，也不能被敌方能力选择。[官方] ✅
- 交战时双方同时造成等于各自攻击力的伤害，然后生命值 ≤ 0 的随从被破坏。[官方] ✅
- "每回合可以攻击 N 次"是被赋予的能力，重复获得不叠加。[社区] ⬜
- **攻击结算顺序**（社区整理，各步骤有 Q&A 佐证）：

  | 步骤 | 内容 | 状态 |
  |---|---|---|
  | 1 | 宣告攻击 | ✅ |
  | 2 | 攻击方的攻击时、交战时能力结算（按卡面顺序） | ✅ |
  | 3 | 防守方的交战时能力结算；如果第 2 步已经让它离场，则不触发 | ✅ |
  | 4 | 如果第 2 步破坏了被攻击的随从，而攻击方是超进化的，触发击退 | ✅ |
  | 5 | 第 2–4 步引发的触发结算：攻击方一侧在前 | ✅ |
  | 6 | 双方同时造成伤害，标记毁灭 | ✅ |
  | 7 | 生命值 ≤ 0 的随从被破坏；被毁灭的随从被破坏 | ✅ |
  | 8 | 超进化击退 | ✅ |
  | 9 | 死亡触发结算：攻击方一侧的谢幕曲在前 | ✅ |

## 6. 结算规则
- 同一个能力里的效果按卡面顺序**从上到下**结算。[Q&A] ✅
- **触发队列**：条件满足的触发能力排到队尾，正在结算的能力不会被打断；队列清空之后玩家才能继续操作。[社区][Q&A] ✅
- **同时触发时的入队顺序**：[社区][Q&A]
  1. 行动牌自己的入场曲、进化时或启动能力
  2. "本卡进入战场时"能力
  3. 攻击方的攻击时、交战时能力
  4. 防守方的交战时能力
  5. 回合玩家的主战者区域（按获得顺序）
  6. 回合玩家的战场（越早登场越优先）
  7. 非回合玩家的主战者区域
  8. 非回合玩家的战场
  9. 瞬念召唤

  骨架实现了 1、2、3、4、6、8 中用到的部分。
- **失效规则**：谢幕曲以外的能力轮到结算时，来源必须还在战场（或主战者区域）上，否则失效。已经入队的能力，即使来源之后失去了能力，也照常结算。[社区][Q&A] ✅（失去能力这一点 ⬜）
- **回合开始的顺序**：[Q&A]
  1. PP 上限 +1、PP 回满
  2. 检查瞬念召唤条件
  3. 己方纹章（吟唱 -1）
  4. 己方战场的回合开始能力、吟唱 -1
  5. 对手的"对手回合开始时"能力
  6. 瞬念召唤
  7. 结算队列
  8. **抽牌**

  骨架 ✅ 1、4、7、8。
- **回合结束的顺序**：己方纹章 → 己方战场 → 对手纹章 → 对手战场 → 瞬念召唤 → 结算队列 → "直到回合结束"的效果到期。"每个回合结束时"在双方回合都会发动。[Q&A] 骨架 ✅ 己方战场
- **使用卡牌的顺序**：
  1. 这张牌的入场曲
  2. 对"使用卡牌"做出反应的纹章、战场卡牌
  3. 对"进入战场"做出反应的纹章、战场卡牌

  [社区] ✅（纹章 ⬜）
- 入场曲赋予的关键词，在进场那一刻还不存在，所以"带守护的随从进场时"这类能力看不到它们。"每回合一次"的进场触发，多张牌同时进场时只对第一张生效。[Q&A]
- **战场顺序**：每位玩家自己看，最早登场的在最左边。分配伤害按"从最早登场的敌方随从开始"分配。变身不改变位置。[官方] ✅（`order` 字段）

## 7. 伤害、破坏与区域移动
- **伤害**不会小于 0。增减伤害的效果先于"把伤害改成固定值"的效果生效。[官方] ✅
- **-X/-Y 不是伤害**：会降低生命值和生命上限，不会被伤害减免挡住，不会击破屏障，也不算"受到伤害"。[社区] ✅（`buff`）
- 0 点伤害也算"受到伤害"，会触发"受到伤害但没被破坏时"这类能力。[Q&A] ⬜
- **破坏**：己方随从或护符被破坏时，墓场 +1。"不会被能力破坏"挡不住伤害造成的破坏。[官方][Q&A] ✅
- **消失**：从战场、手牌或牌组中移除，不增加墓场，不发动谢幕曲。[官方] ✅
- **离场**：包括被破坏、消失、移动到其他区域；变身不算离场。[官方]
- **返回手牌**：场上获得的伤害和效果都清除，费用修改也清除；手牌满时墓场 +1。[官方][Q&A] ⬜
- **返回牌组**：从手牌返回牌组时，费用修改、魔力增幅次数、奥义计量都保留。[官方] ⬜
- **复制**：保留原卡的伤害和效果，但不保留"本回合已攻击 / 已启动"。[官方] ⬜
- **变身**：伤害和效果都不保留；变身成的随从下个回合才能攻击。[官方] ⬜
- **舍弃**：墓场 +1。使用法术时墓场 +1（时机 [未确认]，引擎放在结算之后）。[官方] ✅

## 8. 费用修改 [社区][Q&A] ⬜
- 按发生顺序依次生效。"费用"指修改后的值，"原本费用"指卡面值。
- 减半向上取整（9 → 5）；费用为 1 时减半不会变成 0。
- 减费可以累积到 0 以下，显示时不低于 0；之后再 +1，可能仍然是 0。
- "把费用变为 N"会覆盖之前的所有修改，之后的修改在它的基础上继续生效。

## 9. 选择目标与随机
- 潜行、灵气、土之印护符不能被敌方能力选择；灵气可以被随机效果命中。[官方] ✅（土之印 ⬜）
- **法术**必须凑齐全部目标才能使用；**入场曲和启动**目标不足时也能使用，但必须尽量多选。部分目标不合法时，其余效果照常结算。[官方][Q&A] ✅
- 随机目标在"当前合法的目标"中均匀选取，每次发动都重新判定。从牌组随机抽牌或检索时，每张实体牌概率相同。[Q&A][社区] ✅（`random_sample`）

## 10. 赛制
- **指定系列**（Rotation）：最新 6 个卡包 + 基础卡；每出一个新卡包，最老的卡包退出。从 2026-04-28 第 7 弹起实行，是天梯的主要赛制。[官方]
- **无限制**（Unlimited）：所有卡包，可能有禁限卡；目前没找到实际的禁限。[官方]
- **无禁止**（Boundless）、**起始系列**（Simplified，第 1 弹 + 基础卡，使用原始版本的能力）：不在本项目范围内。

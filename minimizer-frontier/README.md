# 在生物信息学的一个封闭角落里"推进前沿"：k-mer 采样方案的密度下界（σ = w = 2）

这是一次按"候选生成 + 机械验证 + 人选题"模式做的真实尝试。选题来自 Groot Koerkamp 的综述
《Low Density Minimizers》第 2.5 节列出的 **Open Problem 1**：

> 证明前向采样方案的密度下界 g'_σ(w,k) 在 k ≡ 1 (mod w) 时是紧的；另外在 σ = w = 2 时也是紧的。

本目录是全部代码、数据和结论。**没有找到闭式构造，开放问题没有被解决**；
下面逐条写清楚什么是复现、什么是新算出来的、什么是可证明的改写、什么尝试失败以及为什么。

---

## 1. 问题

- 字母表大小 σ，窗口含 w 个 k-mer，窗口长 w+k−1 个字符。
- 前向方案 f：窗口 → 选中的 k-mer 偏移 ∈ [0,w)，且滑动时选中的绝对位置不后退。
- 上下文 = 长 L = w+k 的串；它"带电"当且仅当后一个窗口选了新位置。
- 密度 = 带电上下文数 / σ^L（这是无限随机串上被选位置比例的精确期望）。
- 下界（Kille 等 2024）：g_σ(w,k) = σ^{-L} Σ_{p | L} M_σ(p)·⌈p/w⌉，M_σ(p) 为长 p 的非周期项链数；
  单调化后 g'_σ(w,k) = max(g_σ(w,k), g_σ(w,k'))，k' 为 ≥ k 的最小的 ≡ 1 (mod w) 的整数。

## 2. 工具（复现文献，确认手里的尺子是准的）

`density.py` 精确计算任意方案的密度；`optimal.py` 用 CP-SAT 求最优前向方案。
校验：随机 minimizer 密度 ≈ 2/(w+1)；k ≡ 1 (mod w) 时最优值全部碰到下界，1 < k < w 时有缺口，
与 Kille 等 2024 年的表一致。

Kille 等人只说"对测试过的小 k 成立"，没有给出范围；这里的范围至少不比文献小。
偶数 k 的行是通过第 4 节的引理 3 从 k+1 的受限问题得到的。

另一个顺手算出的小事实（`minigap.py`）：σ = w = 2、k = 2 时，最优 **minimizer**（遍历全部 4! 个序和两种平局规则）
带电数是 11/16，而最优前向方案是 10/16。所以在 (σ,k,w) = (2,2,2) 这个最小的非平凡参数上，
minimizer 在前向方案中不是最优的。这与 Marçais 等 2018 年"前向方案可以严格优于 minimizer"的观察同一类型，
不是新现象，但给了 GreedyMini 论文的开放问题"哪些 (σ,k,w) 下 minimizer 是最优前向方案"一个具体的否定实例。

## 4. 可证明的改写（这些是本次工作里最有把握的部分）

记 n = k+1 为窗口长度，m = n+1 = k+2 为上下文长度。

**引理 1.** w = 2 时任何 local scheme 自动是前向的。（偏移只有 0 和 1，位置不可能后退。）

**引理 2（图改写，奇数 k）.** 把方案看成 de Bruijn 图 B(2,n) 的顶点二染色 c。
上下文 e（一条边）不带电 ⇔ c(前缀) = 1 且 c(后缀) = 0。长度为 p 的奇圈上，不带电边 ≤ (p−1)/2，
取等 ⇔ 圈上恰有一条单色边。k 为奇数时 m 为奇数，所有项链圈都是奇圈，于是

> 方案最优 ⇔ 每个项链圈（长 m 串的旋转类）恰好有一条单色边 ⇔ 至多一条单色边。

**引理 3（偶数 k 归约到奇数 k+1）.** 密度随 k 单调不增（忽略窗口最后一字符即可把 (2,k) 方案变成 (2,k+1) 方案，
带电数恰好翻倍）。偶数 k 时 g'_2(2,k) = g_2(2,k+1) > g_2(2,k)。于是：
偶数 k 的最优值 = 奇数 k+1 的最优值，且偶数 k 的最优方案恰好是"忽略最后一个字符"的 k+1 最优方案。
所以偶数 k 的紧性 ⇔ 问题 **P(ν)**（ν = k+1 为奇数）有解：

> P(ν)：找 h : {0,1}^ν → {0,1}，使每个长 ν+2 的奇数圈词，其 ν 个字符的滑动窗口序列中恰有一处相邻同色。

P(ν) 的解极少：ν = 3, 5, 7 时分别只有 2、16、25088 个（无约束的奇数情形是 10、98、53840 个）。

**引理 4（全部闭路径的奇偶刻画）.** 记 D 为单色边集。c 存在 ⇔ 1 + 1_D 是上边缘 ⇔
对 B(2,n) 中**任意长度**的闭路径 Z 都有 |Z ∩ D| ≡ |Z| (mod 2)。
这把"每个项链圈恰选一个代表"变成了对所有长度圈词的奇偶约束，是判定候选规则的快速筛子。

**对称性事实（用 SAT 判定，`symsat.py`、`rcsym2.py`、`notinv.py`）.**
- 奇数 k：对测过的所有 k，存在**按位取反不变**的最优染色。这意味着方案可以只依赖相邻字符的异或（游程结构），
  变量数减半；而且这些解的真值表与 P(ν) 的受限解在 ν = 3, 5 时**完全一致**（2 个和 16 个）。
- 奇数 k：存在反向取补不变的最优染色。
- P(ν)（ν ≥ 5）：**只**允许反向取补**反变**的解（h∘rc = 1 − h），不允许反向取补不变、不允许按位取反反变、不允许反向不变。
  任何想在 P(ν) 上成立的闭式规则都必须满足这个反变性，这否决了一大类对称候选。

**ν = 3 的唯一解是 MAJ(w₀, ¬w₁, w₂)**：把窗口奇数位取反后取多数。奇数长度的圈上"交替翻转"必然有一个接缝，
这正是"每圈恰一个缺陷"的来源。但 LP 判定（`thresh.py`）表明 ν = 5 的 16 个解和 ν = 7 的 25088 个解中
**没有一个**是交替翻转后的加权阈值函数，所以多数函数的推广不是线性的。

## 5. 构造性规则的搜索：全部失败，但范围被缩小了

每一类都用引理 2 的精确计数验证（`excess` = 总缺陷数 − 圈数，0 才是最优）：

| 候选规则 | ν = 3, 5, 7, 9, 11, 13 的 excess | 文件 |
|---|---|---|
| 字典序 / co-lex / 交替序最小旋转位置的奇偶（含各种平移） | n ≤ 4 对，n ≥ 6 错 | `reps.py`, `intrinsic.py` |
| Mykkeltveit 式复数扇区代表 | 全错，且错得更多 | `sector.py` |
| 交替翻转 + 多数 | 0, 4, 20, 92, 376 | `pnu.py` |
| 交替翻转 + 游走"最高点先于最低点"（first/last 平局） | 0, 4, 12, 36, 96, 264 | `walkrules.py` |
| 同上 + 时间反演对称的平局规则（极值集跨度） | 0, 4, 4, 20, 64, 176 | `tie2.py` |
| 2-步序上的漂移修正游走锚点 | 甚至不自洽（同一窗口的四种补全给出不同答案） | `arcrule.py` |
| Lyndon 分解 / 最小后缀 / 游程特征及其两两异或 | 无一在 ν = 5 成立 | `lyndon.py` |

最接近的"游走极值"规则在 ν = 7 时与最近的最优解只差 8 个窗口（共 128 个），差的全是极值出现多次的平局情形，
而且这 8 个窗口在反向取补下成对出现、答案相反，与上面的反变性事实一致。
这提示正确的规则是"极值先后"加上一个**反变**而非对称的平局裁决，但我没有找到它。

## 6. 结论

- **新算出来的**：σ = w = 2 下界紧性验证到 k ≤ 16；P(ν) 与无约束问题的解数；对称性可行性表；
  (2,2,2) 上 minimizer 与前向最优的差距 11 vs 10。
- **可证明的改写**：引理 1 到 4、偶数 k 归约、ν = 3 的 MAJ 刻画。这些把开放问题 1 的 σ = w = 2 情形
  变成了一个很具体的组合问题 P(ν)，并给出了任何构造必须满足的对称性约束。
- **没做到的**：对所有 k 的闭式构造或存在性证明。开放问题仍然开放。
- **诚实的判断**：这个问题比"线性推理"复杂——最优方案必须是全局规则（只依赖窗口局部模式的规则都不行），
  而且必须打破一种自然的对称。SAT 在几秒内就能给出每个 k 的解，但解的结构抗拒简单描述。
  这恰好是"机器能验证、人类（和我）暂时不能解释"的典型形态。

### 8.2 文献：这个问题在另一个领域有远亲

- Flin、Raevskaya、Stimpert、Suomela、Yang，《2-Coloring Cycles in One Round》（arXiv:2603.04235，2026）把"一轮随机二染色圈"
  归约成 de Bruijn 图上的割，但在相反的参数区（词长固定为 3，字母表趋于无穷）。他们唯一的精确值 DB_normal(2) 恰好就是我们 k=2 的最优 10/16。
  两个领域互不知道对方。de Bruijn 图在 n 增长时的最大割没有任何文献处理，证明它会是一个新定理。
- Kille 等 2024 的 ILP 范围是 1≤w,k≤12、12 小时、128 线程；他们的猜想 1 只覆盖 k≡1 (mod w)，σ=w=2 的偶数 k 只是观察。
- Shur、Tziony、Orenstein 2026 的表 A1 给出 w=2 的前向最优值到 k=11，与第 3 节逐项相同；本仓库把范围推到 k=17。
- Shur 2025（arXiv:2506.05277）定理 11 给出 (2,2,w)-minimizer 最小密度的闭式 (2^w+w+5)/2^{w+2}，是这一带唯一的闭式结果，但在对偶参数区（k 固定、w 变）。

### 8.3 被证明的：定理 A

对奇数 ν，h 是 P(ν) 的解 ⇔ h∘Δ 是 B(2,ν+1) 的最优染色（Δ 为相邻异或映射）。
恒等式 excess(h,ν) = 2·mono(h) − N(ν+2)，机器核验 ν=3..11 无一例外。
推论：P(ν) ⇔ maxcut(B(2,ν)) = 2^{ν+1} − N(ν+2)/2；偶权项链的约束已经蕴含奇权的。
统一猜想：maxcut(B(2,n)) = 2^{n+1} − N(n+1)（n 偶）、2^{n+1} − N(n+2)/2（n 奇），n≤7 直接验证、n≤18 由 SAT 验证。
这解释了第 4 节里我只观察到的"取反不变解与受限解重合"。

### 8.4 任何精确规则必须满足的结构事实（V = 复核者确认，U = 探索者脚本）

1. (V) 多面体捷径不通：B(2,6)、B(2,8) 含奇 K5 子式，Guenin 定理不适用。
2. (U) 强制核：按 w_i ⊕ (i mod 2) 给每个跳变分类，若所有跳变同类，h 等于该类。ν≤7 时这就是全部强制窗口（8、24、66 个）。
3. (U) 四类定理：模输入输出取补，每个解都是"上升沿选择器"：h(W) 是某个 01 边下标的奇偶，且 h(1^a0^b)=a mod 2。
   ν=5、7 时四类各占 1/4，ν=9、11、13 的 SAT 找不到类外的解。纯游程规则因此不可能。
4. (U) 三级 minimizer：ν≤7 的每个解都是 (ν−1)-mer 上的 minimizer，常量窗口处平局方向相反；
   三个秩级（B(2,ν−1) 的一个正常 3 染色）足够，ν=3..13 可满足，两级不可满足。
5. (U) 遗传链：存在 rc 反变链 h_3..h_13 满足 h(00W)=h(W11)=h_{ν−2}(W)，h(0W1)=1−h_{ν−2}(W)。
6. (U，两条路独立得到) 游走规则**不能靠平局规则修好**：在唯一极值窗口上固定它，ν=9、11 不可满足。
   奇弧引理：奇圈词的三个窗口若两两弧长均为奇数，则不能同色，这是筛候选规则的廉价检查。
7. (U) 缝块律：翻一位把缝移动偶数距离，被扫过的块包含 p+1、p+2 两者或都不含；约 2/3 的单位翻转会移动缝，内容算术锚点因此出局。
8. (U) 第 4 节"必须 rc 反变"是我的过度声明：rc 反变**可行但不必要**，P(5) 只有 8/16、P(7) 只有 448/25088 的解满足它。已在 PROBLEM.md 中更正。

KARDS 赛事 BT 实力榜

用 Bradley–Terry 模型给每位选手估一个实力分（Elo 刻度，场均 1500），每站比赛结束后重新拟合一次，所以能看到分数怎样随时间变化。旧比赛按一年半衰期逐渐降权，新人会被先验拉向平均分。

数据范围

已收录 983 Media 主办的 KARDS Open 公开赛（Battlefy + start.gg，含瑞士轮资格赛和正赛）和 2021、2022 世界赛（start.gg，约 100 人的小组循环赛 + 双败淘汰赛）。官方 OCC 月赛、扩展赛、2023 年及以后的世界赛在 Challonge 上，需要 API key，暂未计入。

#选手BT 分± 区间（±1 标准误）较上站 对局最近参赛

怎么算的

每场比赛（一个 Bo3/Bo5 系列赛算一场）给出“谁赢了谁”。BT 模型假设：

P(i 胜 j) = 1 / (1 + e−(βi − βj))，　BT 分 = 1500 + β × 400 / ln 10
  • 随时间变化：每站比赛结束后，用截至当天的全部对局重新拟合；距今 d 天的对局权重为 0.5d/365。
  • 先验：β ~ N(0, 0.8²)，相当于每人先带一点“平均水平”的虚拟战绩，只打过两三场的人不会被冲到榜首。
  • 区间：± 是拉普拉斯近似给出的 1 个标准误。场次越少，区间越宽。
  • 参数怎么定的：用每站赛前的分数预测这一站的胜负，在半衰期 90–730 天、先验 0.4–1.5 的网格里挑样本外 log loss 最低的组合（0.660，抛硬币是 0.693；预测准确率约 59%）。
  • 排除：轮空、弃权/取消资格、双败的对局；Weekday Skirmish、Blitz 等特殊规则的社区赛不计入。
  • 同一人跨平台：按平台账号 + 游戏内 ID 合并，可在 data/aliases.csv 里手动补充。

# 惊奇的单位

Claude 讲给大学生的信息论：一段约 5 分钟、画在黑板上的动画视频，带中文字幕。核心问题是：**我怎么知道，自己到底知不知道？**

| 文件 | 用途 |
| --- | --- |
| `dist/info-surprise.mp4` | 成品视频，1920×1080，30 fps，字幕已烧录 |
| `dist/info-surprise.srt` | 同一套字幕的独立文件 |
| `dist/standalone.html` | 可交互版本，用浏览器打开即可 |
| `dist/index.html` | 去掉外壳的同一页面，用来发布成 Claude Artifact |
| `src/video.html` | 唯一的源文件 |

## 讲了什么

| # | 章节 | 一句话 |
| --- | --- | --- |
| 00 | 开场 | 「一闪一闪亮晶__」猜得到，几乎没信息；「我明天早饭要吃__」猜不到，才是信息 |
| 01 | 惊奇的单位 | 惊奇 = log₂(1/p)：硬币 1 比特、骰子 2.6 比特、太阳升起 0 比特、彩票头奖约 23 比特 |
| 02 | 一个是非题 | 猜 1–16 的数，每问砍一半，4 问必中：log₂16 = 4 |
| 03 | 熵 | 平均惊奇。很确定时约 0.6 比特，四选一毫无把握时 2 比特 |
| 04 | 先猜，再看 | 先写下猜测和把握，揭晓后算惊奇：真的知道 / 知道自己不知道 / 不知道自己不知道 |
| 05 | 校准 | 说八成把握的事，应该大约对八成；对得更少的地方，就是盲区 |
| 06 | 别删掉意外 | 1964 年贝尔实验室天线里去不掉的噪声，原来是宇宙微波背景 |
| 07 | 带走三句话 | 被吓一跳的时候，你学到的最多 |

画面里的猜测分布和校准数据点是示意；比特和熵的数值按公式算出，宇宙微波背景的故事是史实。

## 重新生成

和 `../answer-video` 用的是同一套引擎：

```bash
node build.cjs     # 生成 dist/*.html，内嵌字形子集
node snap.cjs out  # 可选：截取检查用的画面
node render.cjs    # 渲染 dist/info-surprise.mp4 和 .srt
```

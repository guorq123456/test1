# 一个回答的诞生

Claude 讲给大学生的思考过程图解：一段约 6 分钟、画在「草稿纸」上的动画视频，带中文字幕。

| 文件 | 用途 |
| --- | --- |
| `dist/answer-birth.mp4` | 成品视频，1920×1080，30 fps，字幕已烧录在画面里 |
| `dist/answer-birth.srt` | 同一套字幕的独立文件，播放器里可以开关、调样式 |
| `dist/standalone.html` | 可交互版本，双击用浏览器打开即可：拖进度条、按章节跳转、调速度、开启「朗读字幕」 |
| `dist/index.html` | 同上，去掉了 `<html>` 外壳，用来发布成 Claude Artifact |
| `src/video.html` | 唯一的源文件：所有画面、字幕和时间轴都在这里 |

## 讲了什么

| # | 章节 | 一句话 |
| --- | --- | --- |
| 00 | 开场 | 你问一个问题，几秒后得到回答，中间发生了什么？ |
| 01 | 切成 token | 句子先被切成小碎片，每片对应一个编号 |
| 02 | 变成向量 | 编号换成一串数字，相当于「意义地图」上的坐标 |
| 03 | 注意力 | 读到「她」时回头看上下文，弄清「她」是「小红」 |
| 04 | 层层加工 | 「看一看、算一算」重复很多层 |
| 05 | 预测下一个 | 给每个候选 token 打概率，挑一个接上，循环往复 |
| 06 | 训练 | 预训练猜下一个词；后训练学会做有帮助、诚实、不伤害人的助手 |
| 07 | 打草稿 | 「扩展思考」就是先把中间步骤写出来再回答 |
| 08 | 动手做事 | 理解目标 → 计划 → 执行 → 检查，这个视频本身就是例子 |
| 09 | 实话实说 | 会犯错、看不清自己的内部、知识有截止日期 |
| 10 | 回顾 | 最好的思考，永远是你自己的 |

画面里的 token 切法、编号、概率、坐标都是**示意**，用来讲清原理，不是真实模型的内部数据。

## 怎么改、怎么重新生成

需要 Node.js、[Playwright](https://playwright.dev)（自带 Chromium）、`ffmpeg` 和 `curl`。

```bash
node build.cjs     # src/video.html -> dist/*.html，并把用到的字形子集化后内嵌进页面
node snap.cjs out  # 可选：每句字幕结束时截一帧，方便检查画面
node render.cjs    # 逐帧渲染 dist/answer-birth.mp4 和 .srt（4 核约 5 分钟）
```

每一帧都是「时间 → 画面」的纯函数，所以拖动进度、并行渲染、反复导出得到的画面完全一致。

- **改字幕**：编辑 `src/video.html` 里各幕的 `caps` 数组。每句的时长按字数自动计算（约每秒 5 个字），`hold` 可以给某一句额外多留几秒让动画演完。
- **改画面**：每一幕的 `draw(t, c)` 拿到本幕的时间 `t` 和每句字幕的开始时间 `c[]`，动画都对齐到字幕上。
- **字体**：思源黑体（正文）、思源宋体（标题）、龙藏体（手写批注）、JetBrains Mono（数字）。`build.cjs` 只下载画面实际用到的字，页面约 600 KB，离线也能正常显示。

# svsim：超凡世界对战模拟器

为《影之诗：超凡世界》（Shadowverse: Worlds Beyond）**指定系列**写的规则模拟器。目标是在它上面搭斩杀求解器、搜索型 AI，最后再接强化学习，给自己当陪练和复盘教练。

> 非官方粉丝项目，与 Cygames 无关。游戏内容版权归 Cygames 所有。仓库里有一份指定系列的卡池数值表（卡号、名称、费用、身材、关键词等对战字段）和实现卡牌效果的脚本，不包含官方卡面文字、Q&A 和卡图。

## 现状（v0.5）
- **指定系列全卡池可以对战。** 516 张可用卡，加上衍生物、纹章、信仰、激奏 / 结晶形态，一共 586 个有能力的卡牌定义，全部写好了脚本；任意两套合法卡组都能完整对战。
- **规则引擎**：
  - 基础：PP 和额外能量点、换牌、交战，九个静态关键词和无视守护，先进先出的触发队列，胜负判定；
  - 进化：进化和超进化（含无敌与击退），"本随从进化时"；
  - 主战者区域：纹章、信仰；
  - 职业机制：爆能强化、模式、协作、连击、觉醒、启动、融合、结晶、激奏、唤灵、亡者召还、土之印 / 土之秘术、魔力增幅、瞬念召唤、奥义；
  - 修改：限时 / 永久的身材、关键词和能力，按顺序生效的费用修改，去除所有能力，去除谢幕曲，主战者"受到的伤害 +N"；
  - 区域移动：召唤、复制、变身、返回手牌 / 牌组、从牌组召唤、消失。
- **卡组**：卡组合法性检查，官方卡组哈希的导入导出，随机生成合法卡组。
- **测试**：828 项，其中 679 项是逐张卡牌测试（约 40 条官方 Q&A 转成了测试）。
- **模糊测试**：7 个职业随机卡组交叉对战 4 万局、313 万次行动，每一步检查不变量和 clone 一致性，无失败；826 个卡牌钩子在随机对局里触发了 824 个，剩下两个有单元测试。
- **速度**：单核约 170 局/秒（海盗皇家 vs 跳费龙），随机卡组约 140 局/秒。
- **斩杀**（v0.4 新增）：
  - 斩杀求解器：搜索本回合所有行动顺序，找出必杀路线。随机效果和抽牌当作运气处理，不偷看牌组顺序和随机数；带运气的斩杀给出概率；
  - 会斩杀的智能体：找到必杀就照着打完。随机智能体加上它，对纯随机智能体胜率 73%；
  - 斩杀练习题：从对局里挑出不容易看出来的必杀局面，用中文写出局面和答案。
- **完整对局 AI**（v0.5 新增）：
  - 局面评估函数、一步贪心智能体，以及 ISMCTS（信息集蒙特卡洛树搜索：每次模拟都把对手手牌、牌组顺序和随机结果重新打乱，不偷看）；
  - ISMCTS 每步约 70 毫秒，对贪心胜率 73%（海盗 vs 龙，以及 7 职业随机卡组都是）；
  - 搜索里一步棋的价值是它后面最好的那条打法（运气取平均），所以"先进化再打""先打便宜牌攒连击"这类要接对后续才赚的走法不会被低估；
  - 可以在终端里和 AI 对战，随时要提示、查斩杀。
- **资源流斩杀规划**（玩家的思路）：自动量出每张牌"花多少费、给什么牌、抽几张、能不能弹回、对随从打多少伤害、攻击怎么随连击涨"，在资源上算最大伤害和出牌骨架，再交给引擎验证。会先拆守护（随机伤害只在对手只有一个随从时才算），认识屏障，抽到的牌占格子，手牌快满时会把用不上的牌（比如天宫）融合进花园的指引腾格子。在 120 个破魔虫局面上：必杀从精确搜索的 23 个增加到 45 个，没结论的从 89 个降到 0 个，每个局面从中位数 68 秒降到 0.06 秒；判定"杀不了"的 75 个局面，精确搜索复查一个必杀也没找到。
- **玩家的速算公式**：k 只破魔虫的伤害 = 每次下场的连击数之和，先打的牌每张值 k 点、回手牌只加给后面的、回费相当于 -1 费的牌；再加上拆守护的账（突进妖精顺手撞、死矢最后打、超进化随从撞守护再击退）。不到 1 毫秒算出"打不打得死"并给出分解；在 200 个新局面上，77 个必杀判对 76 个。
- **规划器接进对局 AI**：斩杀智能体可以让规划器先算（`mcts:200+plan`），验证过的连击路线直接照着打。MCTS 操作破魔虫打跳费龙，胜率从 8% 提到 15%（各 200 局）。再加"下回合斩杀潜力"评估和"规划器提方案"后到 22%，离高手的 60% 以上还远：整盘打法还不懂得为斩杀回合攒资源。
- **图形界面（手机可用）**：点牌出牌的单屏牌桌。可以在电脑上开本地服务器（手机连同一个 Wi-Fi 打开），也可以打包成完全在浏览器里运行的版本（Pyodide），发布后手机直接打开；每局自动存档。
- **学习评估函数**：用自对弈的胜负和玩家的对局给每套牌学一份局面评估（通用特征的逻辑回归，不针对卡组）。跳费龙学会了跳费，对破魔虫 AI 胜率 83% → 97%，网页里的 AI 已经换上；破魔虫学到了更像玩家的判断（整回合命中 23% → 55%），但实战还没提高，需要更多高手对局和非线性的价值网络。
- **胜负影响**：不给手牌、场面定固定分值，而是数"回合"：双方各还要几个回合能斩杀（时钟），一种打法让对手的 AI 在几种可能的手牌下回应一遍后，双方时钟怎么变、场面被解掉多少、对手花了多少。在玩家的 6 局里，现在的评估函数多数时候认为 AI 的回合打得更好（28 对 12），按时钟来量则多数时候认为玩家的更好（19 对 8）。网页复盘里点"胜负影响"就能看每个回合的对比。拿它在 AI 自己的几条路线里挑（`impact:200+plan`），破魔虫对跳费龙 31% 对 27%，还在误差范围内：候选路线本身还缺高手那种为斩杀回合铺路的打法。
- **打木桩**：让一套牌自己打（对手不出牌），看最快第几回合能打满 20 点；按玩家的前提，对手每回合会解掉多少随从，是从对局里学出来的（第几回合、几点血的随从活下来的比例）。破魔虫自己找到了"先过牌、再一回合爆发"；随从不被解时第 6 回合就能打死，加上解场后是第 9 回合，和玩家实战第 8～10 回合斩杀对得上。
- **卡组分析器**：不告诉它任何卡组知识，自动量出一套牌怎么赢、多快赢、靠哪张牌、怕谁（打木桩 + AI 互打 + 对局记录统计），输出中文报告。已导入 Game8 环境 Tier 表里的海盗皇家、跳费龙、连击精灵、快攻龙，报告见 [docs/meta-report.md](docs/meta-report.md)。
- **对局记录和复盘**：人机对战自动保存每一局，结束时给出回放码；复盘工具在你的每个决策点对比 AI 会怎么走、怎么估值。网页里可以逐步回放打完的对局，把自己的失误标出来、写备注，学习时会跳过这些操作。
- **CR（职业积分）**：按玩家给的天梯规则（GM 底分、200 分匹配范围、每局 16 ± 差距/25、175 分以上 8/24）给 AI 的各个版本和玩家定分，附 90% 区间。现在还没有合适的基准，正式测算暂停。
- **无限模式卡组**：支持玩家提供的「破魔虫精灵」（屠戮破魔虫连击卡组），为它补写了 9 张非指定系列的牌；卡池表也收录了其余所有牌的数值，方便以后加别的无限模式卡组。
- **裁定**：写卡时拿不准的地方已全部由玩家确认，记录在[架构设计 §13](docs/architecture.md#已确认的卡牌细节)。

## 快速开始

```bash
pip install pytest
python -m pytest                                               # 运行测试
python -m svsim.tools.selfplay --games 1000 --decks starter     # 海盗皇家 vs 跳费龙随机自对弈
python -m svsim.tools.selfplay --games 1000 --decks random      # 随机职业、随机合法卡组
python -m svsim.tools.coverage --games 5000 --decks random      # 哪些卡牌钩子从没触发过
python -m svsim.tools.play                                      # 和 AI 对战（你：海盗皇家，AI：跳费龙）
python -m svsim.tools.arena --agents greedy mcts:200 --games 100  # AI 循环赛
python -m svsim.tools.arena --decks rhino --agents mcts:200 mcts:200+plan  # 破魔虫精灵 vs 跳费龙，带不带规划器
python -m svsim.tools.web                                       # 图形界面：浏览器打开，手机连同一个 Wi-Fi 也行
python -m svsim.tools.web --build dist/web                      # 打包成完全在浏览器里运行的版本
python -m svsim.tools.play --you rhino --ai mcts:400+plan       # 命令行版对战（自动保存，给回放码）
python -m svsim.tools.learn --decks rhino ramp --games 400 --iterations 2  # 自对弈学评估（可加 --human replays/ 学玩家的对局）
python -m svsim.tools.cr --games 100 --human replays/ --anchor 1600   # 给 AI 定 CR（以你的 CR 为基准；暂未正式使用）
python -m svsim.tools.review replays/<文件名>.json               # 复盘：你的每一步和 AI 的选择对比
python -m svsim.tools.lethal puzzles --count 5                  # 生成 5 道斩杀练习题
python -m svsim.tools.lethal match --games 200                  # 会斩杀的智能体 vs 随机智能体
python -m svsim.tools.fetch_cards --lang en                     # 拉取官方卡牌数据到 data/raw/（不会提交）
python -m svsim.tools.card_text --craft forest --todo           # 对照卡面文字检查脚本（需要上一步的数据）
```

## 边界
本项目只做**离线**模拟器：不接入游戏客户端，不解包客户端，不分发官方卡牌数据库原文（用户协议第 5、11 条）。

# 算子工坊（Demo）

一款单机卡牌游戏：用已有的**单卡**、**算子**和**卡组**互相配合，合成出新的单卡、算子和卡组。从"数数"开始，一直走到用身体丈量世界。

## 四种卡

| 卡 | 是什么 | 例子 |
|---|---|---|
| 单卡 | 一个值：数、余数、多项式、向量、矩阵、带单位的量 | `0`、`1/2`、`[3]₁₂`、`x² + 1`、`(1, 0)`、`3 步` |
| 算子（轴） | 运算规则，分三类 | 见下表 |
| 卡组 | 用算子把单卡"横向拓展"出来的集合或群 | ℕ、ℤ、偶数、{±1}、ℤ₁₂、C₄、长度 |
| 缺口 | 某条法在某个世界里走不出去的地方 | 负整数（ℕ 做减法）、√2（ℕ 开方）、1/0 |

| 算子 | 作用 | 例子 |
|---|---|---|
| 二元算子 | 两个输入的运算 | 加法、减法、乘法、除法、乘方、取余、拼接 |
| 一元算子 | 一个输入的变换，由二元算子绑定一个数得到，或章节赠送 | `x + 1`、`2x`、`x²`、`1/x`、`2ˣ`、求导、转置、行列式 |
| 构造算子 | 改造算子、生成卡组、填缺口 | 延展 ⟳、封闭 ⟨⟩、逆 ⁻¹、复合 ∘、并 ∪、交 ∩、反推 ↤、填 ⊞ |

开局只有 `0`、`1`、加法和八个构造算子（延展、封闭、逆、复合、并、交、反推、填）。减、乘、除、乘方都要自己合成：加法的**逆**是减法，把加法**延展**（反复做）就是乘法，减法延展就是取余。

## v0.3：尝试不再失败

从 v0.3 起，游戏的每一步是一次**尝试**：结果分成"成立的部分"和"缺口"两份，不再有"合不成"。

- **缺口卡**：某条法在某个世界里走不出去的地方，有三类：没有定义（1 ÷ 0）、表示不了（√2、多项式除法的分式）、越出世界（在 ℕ 里做减法跑出去的负整数）。缺口会自己认名字：ℕ − ℕ 的越出部分就叫"负整数"。
- **底板「在……里」**：把一个卡组放进合成台上方的底板格，这一次合成就限制在这个世界里，跑出去的结果成为缺口。结果换了一种东西（在 ℤ 里做 mod 12 得到时钟，长度 × 长度得到面积）不算缺口，拿掉底板就能直接得到它。
- **填**：对一张缺口按「填」，得到图鉴里包含原世界和跑出去的部分、又能让那条法走通的最小世界：ℕ 的减法缺口填出 ℤ，ℤ 的除法缺口填出 ℚ。图鉴里找不到的缺口叫**前沿**（比如 √ 的缺口）。自己用现有的卡凑一个合规的卡组来**手填**，奖励更高：恰到好处 / 多了一块 / 比图鉴更紧（比图鉴的答案更小，算首次发现）/ 首次发现。
- **反推**：没有逆的算子也能倒推，得到卡组 { x | f(x) ∈ X }：x² 反推 4 → {−2, 2}，x + 1 反推 偶数 → 奇数。

接口约定见 `docs/v03-step1.md`。

## 怎么合成

合成台有三格：**[左] [算子] [右]**。空着的左右格代表变量 x。

- `1` `+` `1` → 单卡 `2`
- `□` `+` `1` → 一元算子 `x + 1`
- `0` `延展` `x + 1` → 卡组 ℕ = {0, 1, 2, 3, …}
- `ℕ` `∪` `负整数` → 卡组 ℤ
- `ℤ` `÷` `ℕ⁺` → 卡组 ℚ（两两运算）
- `偶数` `+` `1` → 卡组 奇数（卡组里每张卡都做 x + 1）
- `2` `封闭` `÷` → 卡组 2ᶻ（反复组合，直到得不到新卡）
- `ℤ` `mod` `12` → 卡组 ℤ₁₂（时钟）
- `(1, 0)` `|` `(0, 1)` → 单卡 `[1 0; 0 1]`（两个向量拼成矩阵）
- `长度` `÷` `时间` → 卡组 速度

## 章节（55 个卡组）

| 章 | 主题 | 卡组 | 解锁 |
|---|---|---|---|
| 一 · 数数 | 初等 | ℕ、ℕ⁺、平方数、2ⁿ | 开局 |
| 二 · 负数与对称 | 初等 | 负整数、ℤ、{±1}、∅ | 开局 |
| 三 · 奇与偶 | 初等 | 偶数、奇数 | 开局 |
| 四 · 分数 | 初等 | 单位分数、ℚ⁺、2ᶻ、ℚ | 开局 |
| 五 · 时钟与余数 | 模运算与有限群 | ℤ₁₂、ℤ₁₂ˣ、⟨2⟩⟨3⟩⟨6⟩、ℤ₇、ℤ₇ˣ、平方剩余、ℤ₂ | 拿到 ℤ |
| 六 · 未知数 | 多项式与微积分 | 单项式、正比例式、一次式、平方项、二次式、完全平方式、ℚ∖{0} | 拿到 ℚ |
| 七 · 方向与变换 | 向量与矩阵 | x 轴、y 轴、四方向、ℤ²、ℚ²、C₄、反射、D₄、对角、标量、M₂、GL₂ | 拿到 ℚ |
| 八 · 以身为尺 | 身体尺度与量纲 | 长度、时间、质量、面积、体积、速度、加速度、频率、力、能量、功率 | 拿到 ℚ⁺ |

第八章是"人类具身认知"的部分：以身体为尺（步、息、捧；拃、庹、里、刻、日、石），运算把它们变成面积、速度、力，量纲的概念从身体里长出来。

**每个卡组都可以由其余的卡组合成**：图鉴里每个卡组至少有两种做法，其中至少一种用到了别的卡组。自动测试会检查这一点，并从开局手牌出发实际走一遍，确认 55 个卡组全都造得出来。

玩家不一定要照图鉴的做法。只要数学上结果相同，游戏就能认出来：`负整数 × 负整数` 会被认成 ℕ⁺，`一次式 经 求导` 会被认成 ℚ∖{0}，`D₄ 经 行列式` 会被认成 {±1}。图鉴以外的结果会成为"自造卡组"。

## 运行

游戏是纯静态网页，没有依赖。

```bash
npm start      # 用 python 起一个本地服务器，然后打开 http://localhost:8000
npm test       # 运行测试（需要 Node 18+）
```

### 卡组是怎么判断"是哪个卡组"的

卡组用成员判断 `has(x)` 表示。像、并、交、延展这些操作能精确推算；封闭、两两运算没法精确推算，就在类型的"视野"（一批有代表性的值）里真的算一遍。得到结果后，在一组探针上和图鉴里同类型的卡组逐一比对；精确卡组还会在它自己的"边界值"（起点、起点的前一步、源卡组样本的像）上再比一遍，避免探针之外的差别被漏掉。

### 加新内容

- 初等篇：在 `src/catalog.js` 的 `CATALOG` 里加一项。
- 新领域：照 `src/domains/README.md` 写一个模块，在 `src/content.js` 里登记。
- 每个卡组写上 `has`，再写至少两种做法 `recipes`（其中一种用到别的卡组），然后 `npm test`。

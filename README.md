# 算子工坊 · 初等数学篇（Demo）

一款单机卡牌游戏：用已有的**单卡**、**算子**和**卡组**互相配合，合成出新的单卡、算子和卡组。

## 三种卡

| 卡 | 是什么 | 例子 |
|---|---|---|
| 单卡 | 一个数 | `0`、`1`、`−1`、`1/2` |
| 算子（轴） | 运算规则，分三类 | 见下表 |
| 卡组 | 用算子把单卡"横向拓展"出来的集合或群 | ℕ、ℤ、偶数、{±1} |

| 算子 | 作用 | 例子 |
|---|---|---|
| 二元算子 | 两个输入的运算 | 加法、减法、乘法、除法、乘方 |
| 一元算子 | 一个输入的变换，由二元算子绑定一个数得到 | `x + 1`、`2x`、`x²`、`1/x`、`2ˣ` |
| 构造算子 | 改造算子、生成卡组 | 延展 ⟳、封闭 ⟨⟩、逆 ⁻¹、复合 ∘、并 ∪、交 ∩ |

开局只有 `0`、`1`、加法和六个构造算子。减、乘、除、乘方都要自己合成：加法的**逆**是减法，把加法**延展**（反复做）就是乘法。

## 怎么合成

合成台有三格：**[左] [算子] [右]**。空着的左右格代表变量 x。

- `1` `+` `1` → 单卡 `2`
- `□` `+` `1` → 一元算子 `x + 1`
- `0` `延展` `x + 1` → 卡组 ℕ = {0, 1, 2, 3, …}
- `ℕ` `∪` `负整数` → 卡组 ℤ
- `ℤ` `÷` `ℕ⁺` → 卡组 ℚ（两两运算）
- `偶数` `+` `1` → 卡组 奇数（卡组里每张卡都做 x + 1）
- `2` `封闭` `÷` → 卡组 2ᶻ（反复组合，直到得不到新卡）

## 入门卡组（14 个）

| 章 | 卡组 |
|---|---|
| 一 · 数数 | ℕ 自然数、ℕ⁺ 正整数、平方数、2ⁿ |
| 二 · 负数与对称 | 负整数、ℤ 整数、{±1}、∅ 空集 |
| 三 · 奇与偶 | 偶数、奇数 |
| 四 · 分数 | 单位分数、ℚ⁺、2ᶻ、ℚ 有理数 |

**每个卡组都可以由其余的卡组合成**：图鉴里每个卡组至少有两种做法，其中至少一种用到了别的卡组。自动测试会检查这一点，还会从开局手牌出发实际走一遍，确认 14 个卡组全都造得出来。

玩家不一定要照图鉴的做法。只要数学上结果相同，游戏就能认出来。比如 `负整数 × 负整数` 会被认成 ℕ⁺，`ℕ` `经` `(−1)ˣ` 会被认成 {±1}。图鉴以外的结果会成为"自造卡组"。

## 运行

游戏是纯静态网页，没有依赖。

```bash
npm start      # 用 python 起一个本地服务器，然后打开 http://localhost:8000
npm test       # 运行测试（需要 Node 18+）
```

## 代码结构

```
index.html        页面和样式
src/math.js       数学核心：有理数、一元/二元算子、卡组的表示和运算
src/catalog.js    游戏内容：开局手牌、构造算子、图鉴卡组、新手任务
src/rules.js      合成规则：三个格子里放什么，得到什么
src/app.js        界面：合成台、手牌、图鉴、存档
tests/            测试
```

### 卡组是怎么判断"是哪个卡组"的

卡组用成员判断 `has(x)` 表示。映射、并、交、延展这些操作都能精确推算。封闭、两两运算没法精确推算，就在一个小范围内（分子、分母不超过 20）真的算一遍。得到结果后，在一组探针数上和图鉴里的卡组逐一比对，判断是不是同一个卡组。

### 加新卡组

在 `src/catalog.js` 的 `CATALOG` 里加一项：写上成员判断 `has`，再写至少两种做法 `recipes`，其中一种要用到别的卡组。然后运行 `npm test`。

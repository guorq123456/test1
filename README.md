# svsim：超凡世界对战模拟器

为《影之诗：超凡世界》（Shadowverse: Worlds Beyond）**指定系列**写的规则模拟器。目标是在它上面搭斩杀求解器、搜索型 AI，最后再接强化学习，给自己当陪练和复盘教练。

> 非官方粉丝项目，与 Cygames 无关。游戏内容版权归 Cygames 所有。本仓库不包含卡牌数据库、卡面文字和卡图；只有已实现的卡牌，在代码里写了对战用的数值。

## 现状（v0.2）
- **第一组对局可以完整对战：海盗皇家 vs 跳费龙。** 两套卡组的 29 种牌，加上它们的衍生物、纹章、信仰、激奏形态，全部写好了脚本和逐张测试。
- **规则引擎**：
  - 基础：PP 和额外能量点、换牌、交战，九个静态关键词，先进先出的触发队列，胜负判定；
  - 进化：进化和超进化（含无敌与击退）；
  - 主战者区域：纹章、信仰；
  - 新增机制：激奏、舍弃、吟唱推进、主战者伤害上限，以及"使用卡牌 / 随从入场 / 主战者回复"三类监听。
- **卡组**：卡组合法性检查，官方卡组哈希的导入导出。
- **官方数据导入**：读入全部 904 张卡的数值、关键词、纹章、信仰和激奏形态。写死的卡牌数值会和官方数据逐张核对。
- **测试**：93 项，其中 3 项需要先拉取官方数据，否则自动跳过。两套卡组随机对局 3000 局无崩溃；54 个卡牌钩子在随机对局里全部触发过。
- **速度**：两套卡组随机对局约 300 局/秒（单核）。

## 快速开始

```bash
pip install pytest
python -m pytest                              # 运行测试
python -m svsim.tools.selfplay --games 1000 --decks starter  # 海盗皇家 vs 跳费龙随机自对弈
python -m svsim.tools.coverage --games 500    # 哪些卡牌钩子从没触发过
python -m svsim.tools.fetch_cards --lang en   # 拉取官方卡牌数据到 data/raw/（不会提交；加载器目前解析英文卡面）
```

## 边界
本项目只做**离线**模拟器：不接入游戏客户端，不解包客户端，不分发卡牌数据库（用户协议第 5、11 条）。

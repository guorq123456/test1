# svsim：超凡世界对战模拟器

为《影之诗：超凡世界》（Shadowverse: Worlds Beyond）**指定系列**写的规则模拟器。目标是在它上面搭斩杀求解器、搜索型 AI，最后再接强化学习，给自己当陪练和复盘教练。

> 非官方粉丝项目，与 Cygames 无关。卡牌数据和卡图版权归 Cygames 所有，本仓库不包含这些内容。

## 现状（v0.1）
- **规则引擎骨架**：PP 和额外能量点、换牌、进化和超进化（包括无敌与击退）、交战，九个静态关键词，入场曲、谢幕曲、攻击时、交战时等钩子，先进先出的触发队列，胜负判定。
- **18 张演示卡**：不是真实卡牌，用来测试各条规则。
- **官方数据导入**：能从官方接口读入全部 904 张卡的数值和关键词。
- **29 项测试**：规则、交战、进化、触发、随机对局模糊测试、确定性回放；其中 1 项需要先拉取官方数据，否则自动跳过。
- **速度**：随机对局每秒 400 多局（单核）。

## 快速开始

```bash
pip install pytest
python -m pytest                              # 运行测试
python -m svsim.tools.selfplay --games 1000   # 随机自对弈：冒烟测试 + 速度基准
python -m svsim.tools.fetch_cards --lang en   # 拉取官方卡牌数据到 data/raw/（不会提交；加载器目前解析英文卡面）
```

## 边界
本项目只做**离线**模拟器：不接入游戏客户端，不解包客户端，不分发卡牌数据（用户协议第 5、11 条）。

  - L 是分析线 c661c8a 的 step1_labels（sha256 a67903d0…），也就是 cand-tl 训练用的收缩标签。

## 门之前的检查（analysis/horizon/check_h.py；data/check_read.txt）

**做法：**和 M5 的 (c) 列同一个回归，只是换成候选自己的 ΔV。
- 第 1 步每条打法的 16 个 T 回合末都重建出来，取 M5 的回归量和各评估器胜率的平均。
- **核对：**这里算出的现装模型 ΔV 和 M5 的 m5_pairs 在 6840 对上逐对一致。

**留出开头**（505 对、169 个开头，不含 end）；单位是每单位胜率百分点，区间按开头重抽 2000 次：

| 手牌 | +3.16 | +2.09 | +2.09 | +2.13 | **+2.84** | **+0.75（+0.41～+1.09）** |

- **ΔT 同号率：**现装 73.08%，cand-tl 73.30%，**cand-th 73.76%**，比现装 +0.68%（−2.23%～+3.59%），没有下降。
- **ΔG_end 同号率：**61.95% / 62.54% / 63.13%。
- **训练开头**（4873 对）上方向也一样：
  - 最大 PP：现装 +3.68 → cand-th +8.78（G_end +11.65）；
  - 手牌：+2.04 → +2.62（G_end +3.28）；
  - SEP：+3.10 → −0.26（G_end +0.06）；
  - ΔT 同号率：71.79% → 71.84%。

**判断（架构线程的两条）：**
1. 三样价格都往 G_end 那边移了，区间都不含 0。
   - 最大 PP：留出开头上超过了 G_end，训练开头上还在 G_end 以下。
   - SEP：留出开头上略过了 G_end。
2. ΔT 同号率没有下降，限度是下降不超过 1 个百分点。

两条都满足，可以进门。cand-tl 是没有修正的对照：它也让最大 PP 往上移了一些（+1.73），修正又在这上面多移了将近三倍。

# 回合末价值网络（learn.vnet）的安装目录

这里放各配对的回合末价值网络，文件名 `<卡组>-<卡组>-vnet.npz`。现在是空的：网络还没训练，也没装。

- **接入：** 智能体加 `+vnet`，用这个目录；`+vnet=FOLDER` 用别的目录（路径，或 `svsim/learn/phased_models/FOLDER`）。只换回合末（ENDED）的打分；回合中（act）的打分照旧，某个配对没有网络时也照旧。
- **输入：** 不含卡组 id、deck_key、配对。
  - 双方场上每张牌：卡号嵌入、攻、血、最大血、进化、超进化、九个关键词、这回合还能不能打随从 / 打脸、是不是随从、倒计时。两边共用一层编码器，各自求和。
  - 自己的手牌：学生的编码器（learn.handvalue），可以用 `fit --student` 从训好的学生起步。
  - 标量：对手手牌张数、双方牌库、PP、最大 PP、额外 PP、双方进化点和超进化点、双方 HP、双方回合数、先后手、是不是被评分方行动。
  - 搜索根之后抽到的牌按它所在的池子算，和学生一致。
- **目标：** λ × 终局胜负 + (1 − λ) × 搜索根值，λ 默认 0.5（`fit --lam`）。损失是交叉熵。
- **规模：** 默认嵌入 8、场面 32、手牌 16、隐层 128 / 64，共 22,561 个参数。只用 numpy，存成不带 pickle 的 .npz。
- **数据：** `python -m svsim.learn.vnet rows <自对弈记录> --out rows.jsonl`，每个搜索决策一行，每个回合末一行。字段：`g`、`i`、`moment`（act / ended）、`player`、`raw`（不依赖词表的编码）、`q`（根值；回合末取该回合最后一个决策的根值）、`result`。
- **训练：** `python -m svsim.learn.vnet fit rows.jsonl --out <卡组>-<卡组>-vnet.npz [--moment ended] [--lam 0.5] [--hold-out-every 11] [--student 学生.npz]`。按局留出：g % 11 == 0 的局只评不拟。
